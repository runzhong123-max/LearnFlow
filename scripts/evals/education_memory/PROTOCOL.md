# 教育记忆消融协议 v1

本实验使用脚本化的合成学习轨迹，评估现有教育记忆实现，禁止把结果称为真实学生画像准确率或学习收益。教育目标先于运行结果确定；产品失败不通过修改产品、删场景或改预期来消除。

## 边界

- Harness：当前宿主的真实教学输入 API 函数、概念判题/纠错/复习 API 函数、record_event、reducer、memory worker、ContextPacket、scoped planner 和无模型规划入口。
- Environment：独立子进程、临时 SQLite、人工编写课程题库与固定学生操作、虚拟业务时钟。只预建 Learner/Project/Roadmap/Checkpoint/Session/ConceptQuestion 等身份与内容资产；不预建学习事件、Attempt、KernelState、Fact、Module、Claim。
- API 函数直接接收隔离身份，身份认证 HTTP 中间件不在本轮范围。评分由正式概念/复习/纠错入口执行，实验不得填入假判分事件或伪 attempt_id。结构化资料/概念自述从已登记事件边界进入，其自然语言抽取不在范围。
- 所有模型密钥清空，禁用自动后台任务；网络连接在实验进程中拒绝。Module/Claim 只由真实队列和真实确定性 worker 产生。模拟时间推进不能称为真实经过数日的学习。
- Verifier：预先编写教育预期，独立检查实际持久状态、来源链、可见指导、证据文本与真实规划结果。不得用生产 selector 生成 gold，不以模型裁判或新造规划器替代实际输出。

## 三层评分

1. 画像形成/更新：逐时间点检查证据等级、掌握门、当前偏好/目标、帮助等级和寿命；单独报告语法探针、生命周期、来源完整性。读取消融共用同一个形成快照，此分数不重复计入每个读取组。
2. 教学信息交付：在相同快照和预算上检查当前教学指导，以及有来源且正文包含目标内容的记忆。只命中证据 ID、hash 或隐藏元数据不算交付。不同组预算一致，必要时保留裁剪失败。
3. 实际离线规划：调用现有 `_scoped_planner_context` 和 `generate_learning_task_plan`。按场景验证时间、知识缺口、辅助撤除、当前优先级；既有 fallback 未使用指导时记失败，不在实验中补实现。形成正确、交付正确、计划采用正确分别报告，不合成单一“准确率”。

## 对照

- full：当前完整读包。
- facts_only：在独立读副本中去除 Module/Claim 节点及其边；保留真实五核状态和即时指导。
- recent_facts：同上，只保留每学习者最近 24 个 Fact；保留即时指导。
- no_relations：路径预算为零，其余保持。
- no_guidance：从返回包移除 teaching_guidance，保留独立 adaptation_directives；是教学指导通道的输入干预。
- no_head_cache：每次真实重建 head；检查缓存只影响成本而不改变教育语义。
- no_memory：真实规划器收到空画像上下文；交付层为空。它不删除学习状态或更改判分门。

另外在真实 worker 前/后观察同一轨迹，单列合成可用性，不能当作另一个独立学生。两个预算为 1800/3200 个现有估算单位，每条件重复两次用于确定性核验，不增加独立样本量。记录完整 JSON 长度和包体估算，不能当作实际模型 token/费用。

`no_guidance` 的 manifest 保留移除指导前的预算估算，仅用于核验原始包未超预算。费用对照使用返回包长度并明确是字符数；不把字符数冒充模型计费 token。所有读副本先用当前状态暖一次 head；查询事务回滚。计时覆盖 scoped planner context 和真实离线计划生成，不包含独立审计和建库成本。

## 场景与审计

学习起点自述；时间预算与卡点；卡点解决及单轮消费；长期偏好/本次覆盖/取消/乱序；负荷同会话/跨会话/过期；引用和第三方负例；自然表述未覆盖探针；探索/确认/修改目标；同概念多次自述与真实合成；历史背景干扰；错答—换讲法—受助重做—变式；缺失/跳过/不会；独立复习与模拟跨 72 小时验证；跨学生/课程隔离；重复提交。

课程题库涵盖数学、物理、编程、生物；相同机制换题面不算独立机制发现。原题与人工审核变式是预设内容，不能宣称验证了自动出题质量。

保留协议、脚本与被测源文件 hash、逐操作返回、逐时间点状态、合成运行、每条件的包/规划/判据结果、未通过列表、命令和环境信息。输出目录必须新建，禁止覆盖旧实验。先执行 driver/评分器校准与小规模试运行，再冻结正式运行；试运行用于修复测量错误，所有版本差异与失败保留。当前结果是开发场景实验，不是盲测泛化评测。

正式固定 4 条主学习轨迹，每条 41 个观测点，另有每条一个外部学习者隔离负例、另一课程和两种会话。每条插入 32 条无关课堂接触事件形成历史干扰。形成正向指导判据绑定本次操作产生的 Event ID，旧的同值指导不能代替新的输入。冷启动无 Fact 的来源链审计为不适用；安全排除、正向交付和规划采用分别汇总。相同题面不同 ID 的稳定升级是教育鲁棒性探针，不冒充现行“不同 item_id”规则的回归测试。

范围限制：本轮只审计实际 profile 输出，未为全部 profile 展示字段编写独立 gold；语义模型提取、在线 LLM 摘要/讲解/规划、浏览器 UI 和真实学习收益均未评估。no_relations 只消融 ContextPacket.relation_paths，个人概念图通道保留；本轮没有前置依赖图的单独教育 gold，不能据此认定关系层无用。
