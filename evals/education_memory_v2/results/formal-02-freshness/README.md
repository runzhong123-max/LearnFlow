# 保留的初始时序诊断

此目录是初始事后诊断，**后续结论使用 `../formal-02-freshness-v2/`，不使用这里的通过率单独证明正确性**。

独立复核发现初始工具没有将决策 Event 与当前 packet 实际交付绑定，也没有按当前 session 过滤 transient Fact。原来 17 项测试未覆盖这两个反例。此处原统计、来源清单和当时的工具/测试源码均保留，便于解释诊断方法为何更新；正式 `formal-02` 的原评分与 gold 未被改写。

新版工具补上交付身份、来源片段与 scope 校验；无动作是 NA，未交付来源是 invalid，不能当作新鲜性通过。使用同一原始运行重新计算并写到新目录，仍标记事后审计，不冒充预设教学评分或教师评判。
