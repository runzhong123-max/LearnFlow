# 网络、系统运维、数据与 AI 作者说明

这是一份原创合成课程任务草稿，不是真实学生记录，不含学生个人信息。作者为代码助手，没有经过教师审核，不声称内容效度、区分度或教学收益已经验证。当前只构建数据，不运行产品消融或模型成绩评测。

## 范围

- `networks`：8 族、24 题。子网边界、路由优先级、顺序 ACL、TCP 重组、IPv4 MTU、窗口吞吐、DNS 缓存、NAT 生命周期。
- `systems`：8 族、24 题。构建 Worker 轮转、双资源准入、LRU 缓存、Unix 权限、阵列故障、p95/SLO、磁盘占用、失败重试幂等。
- `data_ai`：8 族、24 题。类别不平衡指标、预处理泄漏、约束阈值、分组隔离、分层漂移、距离缩放、时序可见性、数据质量。

没有保留与另组重复的 SQL JOIN、SQL 窗口、事务调度或最短路径题族。网络使用 `.test`、RFC 文档 IPv4 网段和 `2001:db8::/32`，全部为离线题内输入。系统题的算法均置于服务工单、配置或观测记录中；调度、资源安全和阵列只采用题内明确的简化模型，不冒充真实操作系统或存储恢复保证。

每族恰好 base、near_transfer、delayed_transfer 三个不同边界案例。变化包括规则顺序与回包方向、缓存类型与过期、时间片边界与空闲、硬链接与最后句柄、零分母与弃权口径、可行候选为空、允许已知用户的新会话、事件时间与可用时间不一致等。不是只替换名称或数值。

`source_basis` 仅是课程对齐标签，不表示课程规范作者提供或认可这些题。学习优先事项、误解假设和返回锚点是轨迹构建素材，不是对任何真实学生的诊断。

## 实际执行的校验

运行命令：

```bash
python3 /private/tmp/learnflow-computing-dataset/operations_check.py --catalog /private/tmp/learnflow-computing-dataset/operations.json
```

最终结果：24 族、72 题；69 个 `executable` oracle 全部通过，3 题为 `reasoned_draft`，错误列表为空。标准库脚本输出 JSON，`checked_oracle_ids` 明确列出实际检查的 69 个 ID；任何不一致均非零退出。

每个执行校验都：读取题内 `oracle_input`，确认其完整 JSON 同样出现在学生可见 `artifact`；独立按算法重算；解析并比较保存的正确回答；确认保存的错误回答不等于重算结果。算法不读取正确回答作为计算输入，不用硬编码答案长度替代计算，不执行题目代码或外部请求，没有 `eval`、动态 `exec` 或网络调用。

具体重算覆盖：IP 掩码与匹配、ACL 五元组、字节区间并集、合法分片、带宽时延积、缓存时限、NAT 映射、轮转队列、安全序列、LRU、权限位、阵列容量与故障组合、频数分位数、inode 引用、重试提交、混淆矩阵、受约束阈值、集合隔离、标准化比例、训练方差距离、双时间戳筛选和数据质量聚合。

另已实际运行结构检查：所需字段完整，ASCII family_id 唯一，每域8族，每族3题，2–4个先修概念，项目背景至少两句，三个题面输入互不相同，正误回答不同，各题至少两个可观察检查点。难度分布为 networks 2/4/2、systems 2/4/2、data_ai 2/3/3，依次对应 foundation/intermediate/integrated。

## 尚需语义复审的部分

三个 `data_ai_preprocessing_leakage` 题检查标准化、折内 PCA 和目标编码的 fit 边界。它们明确标记 `reasoned_draft`、`oracle_id=null`，没有把文字审查称为可执行证明。第三题的类别配置为 A,A,B,C,B,C；折1训练 A/B、验证含未见 C，折2训练 A/C、验证含未见 B，确实存在未知类别回退边界。

可执行标签仅说明题内确定性数值或离散结论经过计算校验，不证明所有自然语言解释都已审核，更不能自动判定真实学生掌握。结构化参考回答为便于记录而使用“我的结果是：”加对象；后续评测应根据 observable_checks 接受等价表达，不能仅凭字符串差异判学生错误。

需要后续课程教师检查任务难度、专业语境、误解假设的代表性和迁移距离。若增加实际工程条件（真实 Linux 调度、ACL厂商行为、DNS预取、TCP回绕、存储重建风险、统计置信区间等），必须重新定义题面和oracle，不能默认本草稿覆盖。

本轮另一助手的只读复审提出并已修复两点：指标题不再用单一矩阵询问阈值调整前后变化；目标编码题现在包含真正的未见类别。该复审是助手之间的检查，不是独立人类或教师审核。

集成时仅把 task_prompt、当前 probe.prompt 与 artifact 给答题者；correct_response、incorrect_response、explanation、misconception、observable_checks 和 oracle 元信息应留在评测侧，避免答案或评分依据进入被测输入。此处没有编写真实学习者历史或训练模型。
