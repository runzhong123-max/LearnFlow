# 课程依据与内容来源

所有题面、数据、日志、代码片段、学生回答与学习轨迹为本任务原创合成，未采集或复制真实学生个人记录。课程依据用于选择能力方向，不表示标准文件包含或认可这些测试题和教学标签。

| source_basis | 原始来源 | 本次使用方式 |
| --- | --- | --- |
| `moe_software_2025` | 教育部《软件技术专业教学标准（高等职业教育专科）》：[官方 PDF](https://www.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/gdzyjy_zk/zk_dzyxxdl/dzxxdl_jsjl/202502/P020250207533323690137.pdf) | 参考程序设计、数据结构、网站与项目开发、测试等工作任务方向 |
| `moe_network_2025` | 教育部《计算机网络技术专业教学标准（高等职业教育专科）》：[官方 PDF](https://www.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/gdzyjy_zk/zk_dzyxxdl/dzxxdl_jsjl/202502/P020250207533459609558.pdf) | 参考网络支持、集成、运维、应用开发等方向 |

这些链接在 2026-09-08 的前序设计讨论中通过官方域名检索核对。教育部 PDF 的直接打开请求超时；上述领域依据来自可检索的官方正文片段，不声称完整逐页审读或课程标准全覆盖。大学 CS 课程框架也不自动代表高职学生已学内容。

实验方法参考：[WWC Standards Briefs](https://ies.ed.gov/ncee/WWC/standardsbriefs) 对基线、混淆和流失的说明。本次尚无学生试验，不声称符合 WWC 的实证评级。

本校具体专业、年级、授课语言、学时、课程标准和教师材料尚未提供。`level` 是作者建议的任务层级，不是已校准的难度或学生能力标签。
