# 教育记忆等信息反事实读出实验 v1

本协议在正式模型计分调用前冻结。新实验与 v4 的 64,260 条检索/规划条件分开保存，不修改旧结果。全过程无需增加教师标注或学生招募。本研究检验合成证据上的操作一致性，不评价真实学习收益。

## 研究问题与对照

1. 在输入包含完全相同的类型化学习证据时，显式五核分组是否改善真实模型的状态理解？
2. 在原始证据不变时，明确的时效、辅助程度和自述资格注释是否减少错误推断？
3. 当一次反事实干预发生时，应变化的字段能否变化，其余字段是否保持不变？

四条件：`five_kernel_gated`、`flat_gated`、`five_kernel_source`、`flat_source`。平面组保留 kernel 标签；分组因子只改变组织结构和跨核顺序。同一预算下四组具有相同的记录 ID、原始字段、取值与各核内部顺序。gated 是额外输入资格注释，不是读出后使用标准答案修正模型；不应将其解释为整个生产门控系统的因果作用。来源、ownership、作用域与未来事件过滤在四组中均开启。

## 样本与形成

正式集：8 个计算机主题 × 6 类反事实 × 2 侧 = 96 条轨迹、48 对、8 个主题簇。开发集另用 2 个主题，24 条轨迹。六类为：有辅助/独立、最新结果顺序、时间预算、支持请求期限、目标更新、自述/正式测评。每对包含相同背景学习历史。真实异项目和未来事件保留在形成数据中，用于检查读取时隔离。

题目答案通过冻结的 Python/SQL 程序实际执行，保存程序、stdout、hash 与退出码。随后由 LearnFlow 正式概念题接口评分并形成 Attempt 与 EvidenceEvent；控制和自述通过注册事件入口进入 reducer → mutation → state/fact 链。题目是合成封闭选择题，这些程序执行不是学生实际编程成绩。辅助等级是情境声明，不是实测的人类提示干预。数据由作者生成且开发过程可见，不能称独立盲测集或模型绝对未见。

查询只读取查询时刻及所属 scope 的源数据。规范化适配器从真实 Attempt、同源 Event、已应用 Mutation 中取值，保留同源 Fact ID；没有 Fact 的合法控制与有 Fact 的证据分开计数。不将生成内容变成掌握状态。当前正式 API 的概念测评 session_id 为空，应报告为现有范围精度限制，不能伪造 session 绑定。

## 读取、预算与冻结

模型使用当前配置的 `deepseek-v4-flash`，记录请求和返回 alias；该别名不保证权重固定。显式关闭 thinking（OpenAI 格式 extra_body.thinking.type=disabled）；温度 0、单次输出上限 400 tokens、90 秒超时、无自动重试、并发最多 4。连接 smoke 单独保存，不进入分数。正式每条件一次回答，不声称测量了随机重复方差。输出 JSON schema 与确定性操作约定见 CONTRACT.md，四组使用相同系统指令。

输入预算为 2,200 和 8,000 个 `cl100k_base` 编码的序列化消息单位。它是披露的预算代理，不是 DeepSeek 的真实 tokenizer。另记录服务方实际输入/输出 token。统一按事件时间倒序选择前缀，同一事件的所有规范记录作为不可拆分的一组；每加一组都计算四种完整消息长度，只有全部能放入才选择，随后按时间恢复记录顺序。绝不对四组分别截断。预算包括任务、schema、来源元数据和资格注释。8,000 条件必须实查完整证据覆盖，不能仅凭预算名称叫完整上下文。高低预算若选中完全相同信息，应报告为重复输入配置而非预算效应。

冻结源码、协议、数据、形成快照、候选记录、实际发出的 messages、随机顺序及其 SHA256。评分调用顺序由 seed=20260913 固定打乱。调用前落盘预约，含糊中断和失败消耗额度，续跑不悄悄重试。正式计划最多 768 次调用、307,200 个输出 tokens 上限；输入由冻结任务限制。该限制不等于金额上限。未执行、接口错误、截断、无效JSON都留在端到端分母。

## 独立自动判定与统计

Verifier 独立读取真实事件和 Attempt，不调用产品规划函数、表示渲染器、旧 expected_action 或模型裁判。有效期和明确安排按照本研究预先声明的操作约定独立核验；它不是教师认可的最优教学动作。未形成所需控制、输入截断、下游读错分别保留，报告端到端与可用证据视角。

主终点为完整字段正确且引用有效、覆盖关键依据；成对联合正确要求两侧均成功，同时满足语义字段的改变和不变关系。报告逐字段、下一步义务、错误独立/稳定掌握推断、错误拒答、引用有效性与覆盖率。空输出一律失败；信息充分却统一回答“证据不足”不能通过。来源 ID 在每一侧单独验证，不把不同数据库中的自增 ID 相同当成反事实不变量。

所有分组差异按同一病例配对。提供主题簇 bootstrap（8 正式簇、10,000 次、seed=20260913）的探索性区间；小规模作者合成主题簇不能代表学习者总体，区间也不是预注册显著性认证。不能把 768 次调用视为 768 个独立学生。零差异、负差异和不确定结果照实报告，不据分数更改协议、数据或评分。开发错误可修复后另冻 formal；旧开发产物保留。

## 完成与边界

交付生成器、真实形成器、共同输入、真实 reader、独立 verifier、反事实指标、负例回归、冻结产物和报告。本轮不修改生产状态权威、不部署、不推送、不更新日常数据库。未完成的教师盲评、真实课堂学习收益、跨模型复现及外部算法官方复现仍列为后续证据，不算本轮成果。

开发01接口失败保留于独立产物：默认thinking耗尽400 token预算，无最终JSON；正式分数未计算。开发修正仅涉及明确关闭thinking和配置数字类型规范化，未按模型记忆得分调参。参数来源：[DeepSeek官方Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。

正式冻结前的独立开发输入审计：24条、12对、192条件的消息解码信息等价、预算与输入hash一致；8,000档规范记录全部入包。2,200档也保留全部必需来源，因此低预算在本轮主要控制背景负担，不能据此声称解决了关键证据漏召回。正式集需再次独立核验该事实。
