# 教育画像与通用会话记忆联合消融协议 v1

2026-09-08，正式运行前制定。用户已明确要求结合两类测试实际做消融。复用仓库服务级评测入口，不另建 Harbor Agent，不更换产品实现，不根据正式结果调参或改 gold。

## 两条轨道分别回答问题

1. **教育画像**：冻结的 `computing-learner-profile-dataset.v1` 全部72任务族、22经历、1,584轨迹。实际重放可适配的原始操作，再检查形成的状态、证据交付和真实离线规划。原教学语义标签仍待教师审核，不把建议答案关键词变成教学质量评分器。
2. **通用会话检索**：LoCoMo官方固定版本的10段长对话和全部QA清单。把每个对话turn作为中立knowledge核的原文节点，调用真实检索器。仅评价支持证据召回，不调用回答模型，不生成官方QA准确率。它是外部对话投影读取实验，不是LearnFlow原生学习事件形成实验。

两条轨道不合成总分、不混合分母。教育独立分析单位为任务族；通用单位为对话。重复读取、不同预算、同一轨迹的配对不是独立学生或新样本。

## 固定条件

预算统一为1,800 / 3,200个生产估算单位，不冒充模型token或费用。相同轨迹各组使用同一形成快照、当前请求、内容、身份和业务时间。

| 组 | 精确干预 | 解释边界 |
| --- | --- | --- |
| full | 正常读取/规划 | 教育使用真实形成快照；通用使用原文节点投影 |
| facts_only | 仅在隔离读副本去掉Module/Claim及相连边，重建head | 保留其他head、指导和Fact关系，不等于所有摘要全关 |
| recent_facts | facts_only基础上每学习者仅留最近24个Fact节点 | 同时改变层级和历史保留量，是受限基线，不是单组件因果贡献 |
| no_relations | ContextPolicy.max_paths=0 | 仅关闭关系路径输出，不关闭独立概念附件/关系排序语义 |
| no_guidance | 教育返回包去掉历史teaching_guidance，保留当前输入控制 | 以本次实际Event ID识别当前控制；独立adaptation通道保留，后裁剪不重新分配预算 |
| no_memory | 教育移除历史画像，仅保留当前输入原生控制；通用返回空证据 | 当前请求先经过相同生产输入入口，不删除已形成状态 |

LoCoMo无生成的Module/Claim、MemoryEdge或教学指导，因此facts_only和no_relations是未激活负控制，不据此宣称摘要/图层无价值。no_guidance仅在教育侧运行。不得预置官方答案、证据位置、带gold的摘要或查询专用主题标签来制造full优势。

正式矩阵在pilot后、全量运行前固定：教育6组×2预算×1,584轨迹，共19,008条件；LoCoMo主比较仅full/recent_facts/no_memory三组×2预算×1,986问题，共11,916条件。LoCoMo的facts_only/no_relations留在5组、双重复的pilot中验证未激活负控制，不把校准子集称为全量运行。正式每条件一次；pilot的重复只验证确定性。

## 教育输入适配

原始自然语言进入已登记教学输入入口，不把作者topic/有效期/目标注释当作产品已正确提取。可计算题的原始正确/错误回答可映射到预建封闭候选题，再由正式提交入口判题、生成Attempt/Event/reducer/Mutation/Fact，真实worker形成Module/Claim。该适配只检验证据生命周期，不评价自由回答判分、代码执行或自动出题。

开放设计题及缺少正式入口的操作记为adapter_gap，保留全部案例清单和分母。不得填写假attempt_id、直接注入成功事件、手写KernelState，或为绕过缺口临时补产品能力。原文source_retraction的语义不能被偷偷翻译成不等价的Claim撤回。

发生时间和录入时间均按数据可见边界过滤；外部范围/未来记录预过滤的成功属于适配器边界，不能计成下游模型抵抗干扰。所有条件保持current.request及本轮原生控制一致，以实际当前Event ID筛选，不能按gold的值筛选。此no_memory不是旧协议完全清空当前控制的条件，不直接横比。原题ID相同，新题ID不同不自动证明稳定掌握。每个案例独立重置，不合并互斥历史分支。

原生adaptation条目若没有可归属的Event ID，不猜测其是否来自当前输入；no_memory只保留可审计的当前teaching_guidance。资源浏览通过注册的lecture_viewed事件入口模拟，属于合成操作重放，不能声称实际浏览器交互或真实阅读时长。事件条数和实际检索节点条数分别记录。

## 评分

- 教育：分别记录输入适配覆盖、真实判题/来源链/状态断言、实际交付和规划约束。交付分成“有来源的完整原话逐字交付”和“有来源的题目标题交付”两类强度不同的诊断探针，不能合成教学质量或通用召回率；类型化Fact合法省略原话前缀仍可能使严格原话探针失败。另标参考事件未形成Fact与已形成Fact两种分母，但已形成Fact也不保证保存完整原话。无适用判据用null，不把空检查算满分；无教师审核不声称教学策略最优或学习收益。
- 通用：区分证据dia_id命中、实际显示原文覆盖和全部证据齐备。只选中ID或隐藏provenance不等于证据正文交付。逐类别报告；无答案、外部知识、缺失/无效证据标注单列，不把无法核验的标注算产品零分。空记忆不能自动获得“正确拒答”分，因为没有运行回答器。
- 预算、输出字符数、实际延迟单列。多进程同机运行的耗时不用于精密性能排名。不合并工程安全不变量与内容召回平均数。
- 聚合时保留全部失败和适配缺口；成对差值按同一case/预算匹配，再按教育任务族或通用对话聚合。聚类bootstrap仅描述本批固定样本的不确定性，不推断真实学生群体或官方榜单显著性。

## 冻结与审计

先跑评分器校准和开发族小规模pilot。只允许修复测量/环境缺陷，保留其错误与变更；不在本任务优化生产系统。正式输出写入新目录，记录代码/数据/协议SHA-256、源commit、CLI、环境、网络尝试、实际操作/packet/结果。运行后验证源代码未漂移。根据留出结果优化之后，该留出批次不能继续宣称未见。

允许教育按任务族、LoCoMo按对话分成互不重叠的独立进程，分片不改变时间、题目身份、输入、预算或评分。汇总必须核验全量case集合、每case条件集合及源码/数据hash一致；同机并行延迟只作运行观测，不作严格性能因果比较。单独记录条件数、实际检索调用数、规划调用数及校准调用数。

不连接生产数据库，不使用模型密钥，不发送学生资料到外部服务。数据下载发生在离线实验之外；离线实验进程拒绝网络与临时根目录外SQLite访问。

Contract impact：无。新增独立实验适配与评分工具，不修改注册表、API、五核、共享实现或数据库schema。
