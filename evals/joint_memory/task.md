# Task与判据

教育用户请求是数据集当前request，目标是依据有时效、有来源的学习经历提供下一步安排。允许合理诊断、减少或保留必要支持等多种策略；不要求单一措辞，不要求配对输出必然不同。教师未审核的教学方案不由关键词自动裁决。可确定的形成、来源、约束采用由独立断言核验；未支持的适配记录缺口。

通用用户请求为LoCoMo原始question；本轮实际结束点是返回可供回答的证据包。独立读取官方dia_id证据标注，检验输出中是否真的有相应原文；答案字符串及证据标注不进入检索输入。无答案题保留，但缺少回答器时不声称已会拒答。

合格的评测必须拒绝：仅gold ID无正文、截断却算完整、错误scope、答案泄漏、无适用断言算满分、跳过坏标注却不报告、用重复采样扩大独立样本量。有效替代来源/正文应按声明的交付规则通过，不能以hidden reference偏好淘汰有效输出。
