# 校准与先导运行记录

本记录区分测量工具修复与产品失败。正式运行没有根据测试结果调整产品、题目或gold。

教育最终pilot使用一个development任务族的22种经历，6组×2预算×2次读取，共528个试次；真实调用为22次当前控制选择、440次试验检索、528次离线规划。LoCoMo最终pilot为conv-26中的5个问题，5组×2预算×2次读取，50个条件、80次真实检索；同一条件的两次读取不算两个独立样本。全部pilot不得混入正式条件分母。

正式运行前的评分器测试共54项通过（教育36、通用11、聚合7）。教育最终pilot无运行错误、网络尝试、源码漂移或重复内容漂移。通用最终pilot无运行、预算、出处hash或重复内容错误；facts_only、no_relations分别10/10条件与full输出正文一致，符合这两个未激活负控制的预期，不能推出产品摘要与图没有价值。

校准阶段修复过这些测量问题：教育空历史组的预算测量、当前输入来源识别与保留、实际判题和辅助程度的独立验证；通用分片使用全语料统一时钟、固定会话选择。旧pilot目录保留在本机临时目录，最终版本制品hash与概要见[校准证据](results/calibration/evidence.json)。正式前还将单次读取的repeat_stable记为null；只有重复读取才有确定性证据。

最终教育pilot仍保留真实不符合预期的结果：跨会话临时10分钟条件未兑现；原题重做出现原生辅助等级从none降为guided。这后一项是适配保真差异，可能是正确的暴露保护，不能称为掌握证据错误升级。完整结果以正式全量报告为准。

早期pilot曾对桌面宿主做24次读取抽查，使用的驱动早于最终正式冻结版本。本报告不将其算作桌面全量验证；正式数据仅对应Web宿主。原始临时制品可随系统清理而消失，长期复现依靠固定源码、数据身份与重新运行，不能宣称临时目录永久可用。
