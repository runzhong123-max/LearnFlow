# Environment

两条轨道使用独立子进程中的临时SQLite；正式分为4个教育与2个通用分片，共6进程。显式设置数据库URL、空模型凭据、关闭自动后台调度；需要合成时显式运行真实worker。审计钩子拒绝联网及临时根目录外的数据库连接。教育每条互斥轨迹重置；通用每段对话独立learner/project，不跨对话召回。

冻结数据：本仓计算机专业群数据v1；LoCoMo官方`3eb6f2c585f5e1699204e3c3bdf7adc5c28cb376`的`data/locomo10.json`。外部数据仅离线本地使用，下载来源、许可证及最终SHA-256记录在SOURCES.md和运行manifest。

教育业务UTC使用合成历史的时间，生产时间消费者一并冻结；数据库审计时间不改写为假历史。通用保留会话时间，在最后会话之后查询，不伪装成在线逐轮写入。

所有条件使用相同读取预算；隐藏评分资料留控制端。正式结果目录必须新建；调试和正式运行分开，不覆写失败记录。未改变用户日常数据、已安装应用或线上服务。
