# 教育画像与通用会话记忆联合消融报告

2026-09-08。面向计算机专业群的技术评审、比赛答辩与对外展示。

> 已实际完成30,924个条件，未改生产实现或测试gold。最明确的发现是：历史截断严重影响通用证据召回；教育侧的约束形成、有效期和规划执行仍有缺口。本轮没有证据证明完整分层系统带来更好的教学效果。

## 1. 实验问题与证据边界

本轮检验两个相连但不同的问题：学习经历能否经真实证据链形成可用画像、支持下一步规划；真实检索器能否在通用长对话中找到有出处的支持文字。两轨分别计分，不生成“联合记忆准确率”。本轮只增加评测与报告，生产记忆实现保持原样。

教育侧使用上一轮冻结的原创合成测试集；通用侧使用[LoCoMo官方固定版本](https://github.com/snap-research/locomo/blob/3eb6f2c585f5e1699204e3c3bdf7adc5c28cb376/data/locomo10.json)。后者仅用于证据检索，没有运行回答模型或官方QA裁判，不能作为LoCoMo官方准确率。未执行LongMemEval，也未评估多模态理解。来源和许可证见[SOURCES.md](SOURCES.md)。

## 2. 数据与公平干预

| 轨道 | 独立分组 | 输入规模 | 正式条件 |
| --- | --- | --- | --- |
| 教育画像 | 72个任务族 | 9方向、216题、22种经历、1,584轨迹 | 6组×2预算×1,584＝19,008 |
| 通用会话 | 10段对话 | 272会话、5,882turn、1,986问题 | 3组×2预算×1,986＝11,916 |

教育集的开发/验证/公开留出分别为990/198/396轨迹；留出已被作者见过，本轮全量后也不再是未见数据。1,584不是独立学生人数，重复历史分支和不同预算不能扩大独立样本数。216题中207题的可执行oracle在实验进程实际复算；9题为reasoned_draft，对应不可自动核验的能力不评分。所有教学语义标签仍待教师审阅，没有真实学生学习收益证据。

教育使用full、facts_only、recent_facts、no_relations、no_guidance、no_memory六组。通用正式只使用full、recent_facts、no_memory；其数据没有Module/Claim或关系，另外两组仅在pilot做未激活负控制。精确干预与残留通道见[冻结协议](PROTOCOL.md)。特别注意：

- facts_only保留其他head、指导和Fact关系，不等于移除一切摘要；no_relations仅将max_paths设为0，不能代表所有图相关算法关闭。
- recent_facts同时缩短历史并去掉高层节点，是复合基线；full胜过它不能单独证明分层或排序算法贡献。
- no_memory保留本轮原生输入控制。用户当前说“10分钟”的约束各组一样，不能删除当前信息来制造历史记忆优势。
- 预算1,800/3,200采用产品字符估算单位，不是模型实测token；本轮无LLM，因此也没有推断模型费用或端到端回答质量。

教育输入只将原始操作送入正式入口，由真实判题、Event、reducer、Mutation、State、Fact及worker产生记忆。封闭候选题适配不证明自由回答/程序判题能力。范围和双时间扰动由适配器预过滤，不能计为下游防干扰能力。浏览记录为模拟UI事件，不是实际阅读行为。

LoCoMo输入为中立的原文MemoryNode投影；不写伪造的MemoryFact权威链，也不供给答案、gold证据、现成摘要或带答案的主题标签。因此只检验真实读取端，不证明产品已具备通用对话的完整原生写入流程。

## 3. 正式结果

### 3.1 执行完整性

六分片全部正常退出，case/条件集合没有缺失或重复，19,008教育条件、11,916通用条件均保存。实际调用为教育当前控制选择1,584次、试验检索15,840次、离线规划19,008次；通用检索7,944次。空历史条件不虚报检索调用。正式总用时795.85秒，仅描述这次同机并行运行。

运行错误0、被测源码漂移0、离线子进程网络尝试0；所有条件预算检查通过。54项评分器校准测试通过。这些工程检查不是记忆准确率。见[条件完整性与原始制品hash](results/2026-09-08/evidence-manifest.json)、[冻结suite](results/2026-09-08/suite.json)、[逐轨统计](results/2026-09-08/report-tables.json)。

### 3.2 通用会话：保留历史有效，多跳证据仍明显不足

主分析仅含category 1/2/4中引用有效的1,438题。每题先计算命中证据数/该题gold证据数，再对题求均值；“全部齐备”要求一题的全部gold正文均交付。本次出处ID召回与完整正文召回相同，未发现已命中gold被截断而虚获正文分的条件。

| 组 | 正文召回，1800 | 全部齐备，1800 | 正文召回，3200 | 全部齐备，3200 |
| --- | ---: | ---: | ---: | ---: |
| full | 48.72% | 45.06% | 55.41% | 50.83% |
| recent_facts（最近24条） | 2.12% | 1.95% | 2.57% | 2.29% |
| no_memory | 0% | 0% | 0% | 0% |

**分类别结果不能被总均值掩盖。** 下表均为full；外部知识类独立列出，不进入主分析。

| 类别 | 有效题数 | 正文召回，1800 / 3200 | 全部齐备，1800 / 3200 |
| --- | ---: | ---: | ---: |
| 多跳 | 278 | 16.51% / 23.85% | 3.60% / 7.55% |
| 时序 | 320 | 55.52% / 62.81% | 53.44% / 60.00% |
| 单跳 | 840 | 56.79% / 63.04% | 55.60% / 61.67% |
| 外部知识（单列） | 89 | 21.25% / 27.59% | 14.61% / 20.22% |

完整1,986题仍保留在清单中：主类原有1,444题，其中6题引用无效；外部知识96题，其中7题无/坏引用；另446题为对抗问题，不给普通召回或QA拒答成功分。13题无效标注不是产品0分。1,226个原始turn有图像元信息，主分析641题的gold涉及这种turn；本轮未供给caption或图像，因此结果只涉及其文字。

按10段对话等权聚类，full减recent的正文召回差值在1800预算为**46.46个百分点**，2,000次bootstrap的95%区间为[44.71,48.49]；3200为**52.40个百分点**，区间[50.07,54.72]。这描述固定10段对话的差异，不推断真实用户总体或官方榜单显著性。按题加权差值分别为46.59、52.84个百分点，权重不同不要混写。

最近24条候选本身对1,382/1,438主分析题不含任何gold，仅56题可能命中，42题可能齐备；即使完美选择，其按题平均召回的候选可及性上界也仅3.26%。因此巨大差值主要支持“保留历史有价值”，不能单独证明本检索排序、图或分层摘要优于其他算法。多跳齐备率仅7.55%则暴露了当前检索在汇集分散证据上的不足；本轮没有检验激活图层是否能修复它。

### 3.3 教育画像：题目来源容易交付，深层画像语义尚未获得验证

完整重放形成1,794个真实Attempt、12,441个Event、12,151个Mutation、30,789个Fact，以及各1,932个Module和Claim。下表只衡量**带真实来源的题目标题交付**，是弱探针，不包含答案正确性、辅助等级、误解和教学策略的完整语义。每组/预算分母都是1,794个可适配作答来源。

| 组 | 1800交付数 / 1,794 | 交付率 | 3200交付数 / 1,794 | 交付率 |
| --- | ---: | ---: | ---: | ---: |
| full | 1,649 | 91.92% | 1,794 | 100.00% |
| facts_only | 1,645 | 91.69% | 1,794 | 100.00% |
| recent_facts | 1,538 | 85.73% | 1,656 | 92.31% |
| no_relations | 1,649 | 91.92% | 1,794 | 100.00% |
| no_guidance | 1,649 | 91.92% | 1,794 | 100.00% |
| no_memory | 0 | 0% | 0 | 0% |

full/1800有7个来源靠合法Module/Claim闭包及可见文字获得交付；若只看Fact正文则为1,642/1,794，低于facts_only的1,645。这说明评价口径会改变小差值方向。本轮允许有出处且可见的高层文字得到相应分数，没有固定偏袒Fact或Module。

另一项**完整原话逐字交付**探针在所有组都是0/1,152。参考原话没有形成对应可检索Fact，形成gap共1,152个；它主要暴露输入表达/形成与长期保留边界，不能称作全系统的文字召回率为0。时间控制不入长期Fact还包含刻意设计。两类探针不合并为“教育准确率”。

同一历史产生的画像安全检查：1,584/1,584轨迹没有发现稳定掌握升级，Fact来源链检查通过；具有评分Attempt的1,311条轨迹判题与独立复算一致，辅助程度没有被降低。273条轨迹无适用评分，记null。69条原题重做出现requested none、actual guided的适配差异，保留差异记录；它是保守降级而非虚增独立掌握。全量规划均保留验证要求、未提前标记完成，当前控制在各组一致。安全不变量通过不代表教学质量通过。

**实际10分钟规划约束仍失败。** 每组每预算均为：历史临时约束0/72通过，当前输入覆盖19/72通过；两类合计19/144。所有组相同，增大记忆预算没有修复这些约束，历史记忆增益也不能由该分数推出。pilot单一任务族的当前覆盖通过不能推广为全数据通过。

本次平均包估算量full为1,672.3 / 2,254.8，facts_only为1,673.6 / 2,235.5，no_memory为40.7 / 40.7。小预算full相对facts_only只多交付4个题名来源，大预算相同；这些结果不足以证明高层记忆提高教学效果，也不足以据此删除模块。

适配缺口按操作记录：概念提交无法保留原历史session共1,794次；缺失/跳过/不会作答入口未复现207次；未知辅助被拒69次；显式期限未支持144次；另有未执行的环境故障、团队产物、源撤回及90次draft题作答等。全部细分见report-tables.json，不把未适配操作当正确完成。

## 4. 已定位的机制与失败

**跨会话临时约束没有被忠实保留。** 教育case `clp-ae089b2ffe6d83fbab9c` 的原话确实包含“只有10分钟”和有效至次日11:00的ISO期限。原生Event 4解析出minutes=10，却采用session生命周期和固定8小时有效期。次日新session查询时两道条件都不满足，full没有交付该指导，规划为45分钟。问题发生在约束的生命周期表达和形成阶段，不能笼统叫检索漏召回；本轮没有改产品来消除此失败。源码位置为共享包`teaching_guidance.py`的解析/有效期/选择逻辑；原始证据位于education-00形成记录和packet。

**当前控制提取对措辞和题目上下文脆弱。** 当前请求追加的是“但这一次只有10分钟”，规则只匹配“今天/现在/这次/我”等前导，漏了“这一次”。19个成功请求恰有近邻前文“先问我”，规则跨句从“我”匹配；51个请求没有这一近邻而未识别。另2个任务正文含“不是”或“假设”，触发整句过滤，后面真实的时间要求一起丢失。`clp-a754996deacf296defc6`是明确说10分钟、Event存在但human控制为空、实际plan45的例子。各组当前控制一致只证明公平保留相同输出，也可能公平地保留同一个空提取结果，不能把canary通过写成理解成功。

全量3,168个full packet中只有38个带teaching_guidance，均来自19个当前覆盖案例的本轮Event；历史Event来源条目为0。因此full和no_guidance相同属于本测试映射中历史通道未激活，不能证明历史教学指导无用。

**有些原文没有形成可检索事实，有些控制有意不进入长期Fact。** `goal_superseded`和`long_history_return`中的部分自然语言不匹配当前窄规则，Event没有对应Mutation/Fact；不能说它们被最近24条挤掉。另一方面，time_budget属于human teaching_directives，长期Fact排除它是避免过期控制被反复复述的设计。形成交付gap需要分原因处理，不能全部算成产品故障。

**辅助成功与稳定掌握边界在抽查中保持成立。** `clp-e7c700979390f7ad1206`有提示成功保持guided、correct_with_support和mastery_inference=false；`clp-bffbec225444891af742`原题重做被记为guided/retry/independent=false。none变guided属于适配保真差异，不能当成错误升级。未知辅助等级的案例没有伪造Attempt，其判题检查为null。

**上游引用有效不等于语义已经人工审校。** LoCoMo按原始dia_id严格评分，valid仅表示引用存在且格式可解析。质性抽查发现`conv-49:q0103`涉及的日期和gold所在会话日期不一致；`conv-43:q0026`的一些gold并不明确支持所问对象。保留官方引用和原分数，未事后删除难题、改标注或挑选成功样例。这限制了低召回分数能够支持的归因强度。

**更多预算也不保证每题单调变好。** `conv-49:q0109`在full/1800命中一条支持证据，full/3200未命中。按排名贪心装包时，大预算可能纳入更大的前排条目，改变后续短条目的机会。这是预算选择机制的实际差异，不是重复读取漂移。

## 5. 如何解释与下一轮改进

先修复当前控制提取、显式时限、目标更新和跨会话约束的可审计表达，再评估后端排序优化。具体先把任务正文与本轮个人约束分段解析，支持“这次/这一次”等可审计等价表达，避免一句题目中的假设词否决整条请求；显式记录有效期和适用会话，保留原Event来源。新增控制仍需经过EvidenceEvent→reducer→KernelMutation→KernelState；不能为了让实验通过直接注入画像。修复后将本批暴露过的案例作为回归，新一轮独立结论需要新增并经教师封存的任务族。

通用检索需要与相同候选历史、相同预算的替代检索方法比较，才能判断排序/混合检索贡献；最近24条只能回答历史截断问题。图和摘要层需要让这些机制真正激活、且候选形成质量可检查的独立实验，不能用空图负控制或低成本总均值决定去留。

教育场景下一步应由教师审核“经历—证据—下一步任务”的适宜性，并引入经授权、去标识的真实教学轨迹。当前已执行的确定性检查只支持证据边界与部分规划约束；尚不能支持“教学更好”“掌握更稳定”或“学习效率提高”的结论。
