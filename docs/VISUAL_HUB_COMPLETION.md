## 内容和交互标准

每份作品有明确的问题、可操作输入、主要画面、随计算产生的状态与说明、适用范围、章节/session 关联、检索别名和先修信息。输入会影响实际计算与画面，不只是替换标题；参数改变立即重算并回到首帧。不同执行过程即使首尾一致，也要在中间步骤呈现差异，例如随机快排的划分、不同排序方法。

主要画面按机制选择曲线/散点、矩阵、时间线、树、图、数据流或状态对照。共用绘制原语与播放器，不把所有问题都画成一排方框。播放、单步、拖动、速度和重置是一组清晰控制；比较最终结果、完整数据和适用范围折叠收起。未增加常驻追问/改编表单，也不把观看结果写成掌握证据。

树按有序子树宽度展开，父节点居中、叶子分层，哈夫曼 0/1 分支顺序稳定；B+ 叶链不改变树层级。图边贴节点边界，区分有向/无向，双向边分开，自环向外并纳入完整 viewBox。默认显示完整图形，放大后允许横移；较密图表在窄屏保持可读尺寸并明确提示横向滑动。几何图的等比例坐标避免把圆、角度或旋转拉伸。

## 复核中实际修掉的问题

- 哈夫曼树边交叉、深层叶子被固定高度裁住；链表自环标签超出 viewBox；DFA 自环和跨状态标签挤在一起。
- K-means 多帧不改变画面：区分分配/更新、绘制真实样本与中心，并选择能体现重分配的初值。
- 积分动画每步重设纵轴使旧矩形变矮：固定坐标，并按区间宽度画矩形。
- CNN 未计算特征图单元被当作零响应：未计算状态单独留空；响应色标固定，实际计算卷积、ReLU、池化、分类头和 softmax。
- 极限的空心点、跳跃函数被错误连成斜线、空心点被坐标边缘裁半。
- “重置/拖回首帧”后主按钮仍写“重播”：按钮文案随当前播放状态更新。
- 窄屏横溢无提示、树图默认不完整；放大按钮在宽屏没有真正变大。
- 量子相位只画概率难以观察：QFT 补实部/虚部；de Bruijn 重复边以剩余计数表达；PCA/几何示例使用散点和等比例坐标。

CNN 这里是可核算的 **8×8 合成笔画、手工设定权重的机制模型**，演示 1/7 两类及超出类别的输入；没有冒充经过 MNIST 训练的十分类模型。根仓不提交模型权重。不能把它宣称为之前对话中训练模型版 CNN 的完全同一实现。

## 维护方式

源码位于 `packages/learning-core/src/learnflow_core/visuals/hub/authoring/completion/`，分别维护基础、工程、研究、第二批升级和早期作品升级。公共绘图、播放器、样式位于其上一层 `completion-runtime.js`、`completion-player.js`、`completion.css`。

```bash
node scripts/build_visual_hub_completion.cjs
node --test packages/learning-core/src/learnflow_core/visuals/hub/authoring/completion/*.test.cjs
python3 scripts/check_shared_contracts.py --python-web /path/to/web/python --python-desktop /path/to/desktop/python
# 分别在 Web 和 Desktop backend 中执行：
python -m pytest tests/test_visual_hub.py tests/test_visual_library_curriculum.py tests/test_visual_workspace.py tests/test_architecture_registry.py -q
# 分别在两个 frontend 中执行：
npm run build
```

`completion-checks.json` 保存按作品 ID 的配置检查数与最大帧数。构建器只把当前作品需要的课程生成调用编入自含 HTML，保持 helper 闭包；所有资产有 SHA-256，发布后拒绝覆盖同版本文件。后续修订需要提升该作品版本再构建；公共 runtime 改动影响引用它的新版本，旧 HTML 原样保留。

历史第二批构建器只验证并跳过已发布 v1，不会再删除 v2 manifest 或把课程引用降回 v1。新旧 source 引用可并存。当前 HTML manifest 为 359 个版本，另外保留原 15 份 VisualSpec 历史模板；默认检索去重为 296 个作品。

Contract impact：既有 `visual_content_library` / `retrieve_learning_visual`、维护 gallery/preview 与 private workspace 边界不变；没有新主 Agent、API、EventContract 或五核写入。课程内容补齐，目录版本升为 `2026-09-08.1`，检索默认选最新兼容版本，精确历史引用仍可读取。无需数据库迁移。
