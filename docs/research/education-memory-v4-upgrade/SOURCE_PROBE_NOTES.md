# 原生 Fact 补充探针：独立复核与事后更正

本补充在观察到主实验原文探针全零后设计。冻结后首次运行完成 24 案例、96 条件；不是预先固定的主实验，也不进入主实验教育排名。完整记录在 `evals/education_memory_source_probe/results/native-source-probe-01/`。

独立复核重算 24 个 formation 和 96 个 packet/trial，得到相同结果；9 项核验器测试通过。还验证了“目标 ID 与观察句正确、但限定句缺失”的反例仍判失败，计分不是仅检查引用 ID。核对的 192 个源码 hash、制品 hash 与 48 对候选集合均一致。见 [source-probe-independent-audit.json](source-probe-independent-audit.json)。

## 可以说明什么

在这 8 个计算机教育主题、3 种刻意构造的位置模式中，原始字符串经 `user_message → reducer → Mutation → State → Fact` 形成；检索查询只含主题，不含目标观察或限定语。两档预算中，头部模式新旧两组都是 8/8；尾部模式及分散限定语模式，旧读取各为 0/8，新读取各为 8/8。来源合法只证明自述被忠实交付，不代表自述正确或学习者稳定掌握。

同一候选池降低了扩大扫描范围的混杂，但**不是纯正文显示替换实验**。原文同时参与查询匹配与 BM25 排序：48/48 对的排序分数、诊断和估计预算发生变化，24/48 对最终 item ID 或顺序不同。这里测得的是这一整套 source 读取方案的效果，不能把全部差值归给单独的文本显示或截取算法。

## 冻结协议措辞更正

补充协议背景中把原有 1152 条目标统称为来自控制投影，表述过宽。完整追溯实际为 **430 条控制分流、722 条无 mutation**；两类均无对应 Fact。原文完整保存在事件 payload，未发现这些目标的原文截断。冻结协议、数据和原始分数保持原样，用本说明作事后更正。

## 公开与本地保留的制品

安全的合成 `data/cases.jsonl` 与结果快照、packet、trial、错误清单、协议、主要制品 hash 均纳入源码交付。主 `artifact-manifest.json` 所列可计分制品完整保留。

按照仓库规则，`execution.log` 本地保留而不提交。额外的 `custody-manifest.json` 与 `handoff.json` 仍记录其原始 hash/路径；从 Git 克隆的副本不会包含该日志。日志不是独立评分所需的输入。不得因此改写原始 custody 清单，或把日志未发布说成不存在原始执行记录。
