# 论文定位与投稿说明

本稿依据 2026 年 9 月 9 日已归档实验及产品版本 0da6615 编写。英文题目为 **Temporal Validity and Evidence Coverage in Budgeted Memory for Educational Agents**，中文可译为《预算约束下教育智能体记忆的时序适用性与证据覆盖》。正文是一篇完整的系统研究论文初稿，含方法、算法说明、实验设计、完整消融表、失败分析、局限和文献，不是比赛宣传稿。

**目前适合送团队内部学术评审，尚不建议直接投稿。** 最主要的缺口是独立教师核验、具有竞争力的外部基线和真正未见的评测数据。它们关系到证据强度，不是润色或换模板能够解决的问题。本文没有把这些未完成工作写成结果，也没有声称保证 SCI 录用。

## 中文摘要

教育智能体的记忆需要保留学习证据形成时的条件，包括辅助等级、重复作答、作用域与发生时间。来源真实且可追溯的记录，仍可能导致不适用于当前学习状态的教学动作。本文以面向计算机专业群的 LearnFlow 为研究对象，分析确定性事件归约链、带来源的学习经历包和预算受限的上下文构建机制。教育实验包含 1,584 个合成轨迹、12 个配置和两档预算；通用记忆实验采用 LoCoMo 原始对话的证据检索适配，包含七个配置。两轨合计 65,820 次条件执行，不能解释为同等数量的独立学习者。

事后时序审计在完整系统的低预算条件下发现 192 个过时评分引用。按真实事件时间排序并只保留从最新记录开始的连续前缀后，观察到的过时动作降为零；其中 63 个案例产生时序一致的动作，129 个案例转为没有评分驱动动作，说明修复存在覆盖代价。删除学习经历包使低预算题目主题及其源 Fact 交付从 1,407/1,794 提升至 1,640/1,794，但同时移除了基于评分经历的教学准备。LoCoMo 主类的 1,438 道有效题上，完整系统两档预算的平均证据召回率为 48.81% 和 58.00%；关闭 BM25 分别降低 3.60 和 3.67 个百分点。

研究显示，来源正确、时序适用和内容覆盖需要分别评价。全部教育样本已经被作者看过，教师评审尚未完成，实验没有测量真实学生学习增益，也没有执行生成式问答评分。

## 本文真正能主张的贡献

1. **可审计的教育证据边界。** 学习者画像通过 EvidenceEvent → reducer → KernelMutation → KernelState → Fact/Module/Claim 形成；经历包和规划建议是读取投影。辅助成功、原题重做和独立迁移不被直接合并为掌握。
2. **有实证的时序错误机制。** 旧的短成功记录可能在预算竞争中挤掉新的复杂失败或辅助记录。合法来源并不自动保证当前适用。
3. **有代价报告的修复。** 同一校正审计下逐案例比较，明确 192 = 63 个新通过 + 129 个无动作，不把无动作计为正确教学。
4. **教育与通用记忆分别评价。** 教育轨道验证真实服务链上的合成输入；LoCoMo 轨道检验证据检索。不同分母、不同任务和未激活机制不混成总分。

BM25、事件溯源、五个工程状态维度和时间排序本身不宜包装成独立算法创新。更有说服力的研究主线是“教育证据在预算压缩后的决策适用性”，而不是“我们又做了一套记忆图谱”。

## 投稿前最值得补的工作

**首先验证教育数据和评价目标。** 由至少两名计算机专业教师独立审核题目、轨迹、辅助等级和 gold，再对真实生成的方案评价“是否引用最新有效证据、是否错误推断掌握、下一步是否适切、是否足以执行”。应先锁定评分规则，再打分和解盲；不能在看到各组成绩后修改标签。现有 4,752 份计划只是待评材料，当前教师评分数为零。

**建立全新且冻结的测试集。** 按任务族、表达模板、学生轨迹和时间关系隔离开发与测试；包含独立编程、调试、SQL、网络排错、测试设计、团队产物归属、未知辅助、撤回、更换目标、旧失败恢复和证据不足。保持真实执行与封闭识别两类任务的明确标签。现有 historical holdout 已见过，必须改口承认，不能重新命名来制造“未见”数据。

**增加强基线和同预算比较。** 最少补充 BM25、dense、hybrid、长上下文，以及一个维护良好的代表性记忆系统。统一可见数据、输入边界、索引单元、读出模型、原始 token 计数和问答评分，报告检索证据及最终答案。若比较知识追踪，则另设预测任务和相应指标，不能用当前引用探针代替。首次运行必须保存所有失败与超预算样本。

**把时序修复做成更充分的机制实验。** 单独操纵新旧记录长度、先后顺序、辅助等级、结果冲突、候选窗口位置和预算，比较旧打包、连续前缀、最新评分最小摘要等策略。后者尚未实现。主要终点应同时包含过时动作率、最新证据覆盖、无动作率和错误升级掌握率；不以“全部不回答”赢得零错误。

**再决定是否做学生研究。** 如果要主张教学收益，应先完成所需伦理和知情同意程序，预先设计样本量与分析，随机或合理控制先验水平，测量即时成绩、延迟保持、无提示变式迁移和实际学习时间。没有这些数据时，保持系统研究定位即可，不必虚构教育效果。
