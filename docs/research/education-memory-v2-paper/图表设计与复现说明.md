## 文件与重建

`figures_zh/` 中每幅图包含 SVG、PDF、PNG 三种格式：

- SVG：文字与线条保持可编辑，物理尺寸显式以 pt 标记。
- PDF：矢量图，嵌入所用 TrueType 字体子集。
- PNG：450 dpi 的 Word 兼容预览；投稿主图应优先使用矢量版。

`build_paper_zh.py` 从 `derived_results.json` 读取数据，重新核对其引用的留存输入哈希，并断言中文表 4、表 5 与实际汇总一致、无片段配置没有评估动作、时序计数及 18 项引用完整。该脚本不执行新实验，也不修改原始标签。原始逐条件导出及来源链映射仍见 `SUPPLEMENT.md`。

通用重建命令如下，Python 环境需要 python-docx 和 reportlab，Node 环境需要 sharp。`PAPER_FONT_DIR` 可指向含 Arial.ttf、Arial Bold.ttf 和 Arial Unicode.ttf 的合法本地字体目录；系统默认使用 macOS Supplemental 字体目录。字体名称不同的环境须相应调整构建器，不应静默替换为缺字字体。

```bash
python build_paper_zh.py --node /absolute/path/to/node
```

本次使用 Codex 捆绑的 Python 3.12 与 Node 依赖运行。Word 渲染使用同一运行环境的 LibreOffice，不使用用户安装的桌面应用。捆绑渲染器最初未发现中文系统字体；为渲染进程提供临时 Fontconfig 文件、显式读取系统字体目录后修复。配置只作用于本次检查，不安装字体、不更改全局环境。每轮排版修改后重新渲染并检查页面。
