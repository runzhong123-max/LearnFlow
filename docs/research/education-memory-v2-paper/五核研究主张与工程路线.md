# 五核记忆的研究主张与工程路线

2026-09-13。本文配套新版中文论文，区分本轮源码审查、既有实验的事后解释与尚未执行的研究。没有运行新消融、招募学习者或生成教师评分，没有修改产品契约、生产代码或数据库。Contract impact：无。

## 论文的核心回答

五核提供的不是五份互相独立的摘要，而是面向不同教学问题的共同学习状态：Structure 支持位置与返回，Knowledge 保存理解依据，Human 提供明确的支持需求，Value 维护目标优先级，Practice 保存有条件的尝试与验证。共同证据链使这些信息能够关联，又不互相替代为不成立的结论。

其可主张的设计特点是教学责任清晰、证据条件保留、共同状态可追溯和当前解释可纠正。是否因此优于等信息的平面画像，属于待检验的比较假设；既有读取组件消融不能替代五核表示实验。

## 修正两项实验解释

`no_episodes` 每档 1,584 个条件没有评估动作，但仍有 144 个时间限制动作。实际指导只有 Human 时间控制，没有 Practice 反馈。这表明该批轨迹对片段评估入口的依赖；没有让平面基线携带相同证据进入同一接口，就不能证明片段表示优越。

原文探针的 0/1,152 是指定原文在特定读取通路中的送达结果。事后核对发现 430 个目标已有 Mutation 而没有 Fact，另 722 个未关联 Mutation。前者包括 Human 144、Value 214、Structure 72；相关教学控制按设计不重复事实化，以避免过期指令通过摘要重新出现。后者尚未逐条语义审核，可能涉及无需变更或未覆盖输入，不能全部叫解析失败。原始日志计数不等于新实验，原标签与主结果不变。

复核脚本为 `audit_retained_evidence.py`，汇总为 `retained_evidence_audit.json`，包含输入 SHA-256、字段匹配和不含原文的结构例子。重算需要本地 `evals/education_memory_v2/runs/formal-03/education-*` 的四份 formation 和四份 raw 压缩日志；没有将这些原始上下文复制到论文目录，也不声称仅靠公开精简导出能重算所有新增细分。

## 应如何做出有价值的实验

### 先验证组织，再验证信息

首先做共同接口的等价性校准：固定相同已选证据，五核和平面材料经适配后应保留相同字段，确定性动作应相同。这一步发现接口偏置，不用来宣称架构胜出。

主要表示实验让五核和平面结构从同一合法候选池检索，在相同预算下比较所选证据、条件保真和动作适用性；另一路可使用同一冻结读出模型解释等信息材料。统一课程 RAG、来源权限、模型和教学规则。增加教育语义分组、合并知识/实践组织标签与固定随机分组的比较，区分五核语义与一般分组效果。

逐核屏蔽回答的是信息贡献，会减少内容，必须另行报告。遮蔽覆盖 heads、items、Module/Claim、关系端点、概念附件、adaptation、guidance 和 episodes 的依赖闭包；当前输入作为共同控制保留并独立评分。先按核和相关组合进行预实验，再决定是否在经审定的子集上运行 32 种全因子组合，不把组合数量当作独立样本量。

### 用反事实检验应该变化与不应变化的行为

- 同一成功结果，仅改变有提示或独立完成，检查实践动作是否变化、目标是否保持。
- 同一能力证据，仅改变当前已确认目标，检查优先级变化、掌握结论是否保持。
- 同一知识与任务，仅改变支持请求期限，检查节奏或时长变化、能力判断是否保持。
- 同一概念与表现，仅改变暂停位置或依赖，检查返回路径变化、概念结论是否保持。
- 同一历史证据，仅交换新旧评估顺序，检查动作引用与无动作比例。

独立教师标注允许动作集合与禁止推断，系统规则不能自充金标准。新测试按任务族、模板与近重复材料隔离；旧作者已见样本仅作回归。加入真实代码、SQL、调试和项目产物的失败、提示、重试、变式与延迟验证，不以二选一适配代表全部计算机实践。

### 借鉴论文的方法但不继承其成绩

- [DeepTutor §6.1–6.2](https://arxiv.org/html/2604.26962v1)：课程材料、画像条件、知识缺口与交互任务配套；相同导师与模拟器；独立评审。其画像中的隐藏缺口不能直接注入待测导师。
- [LongMemEval §3.3、§5.2–5.5](https://arxiv.org/html/2410.10813v2)：分开检索与最终利用；比较粒度、预算和完整证据输入。完整证据输入只作诊断上界，不能包含答案或混入部署成绩。
- [LoCoMo §3.4、§4](https://aclanthology.org/2024.acl-long.747.pdf)：证据位置标注、跨会话任务与总结事实精确率/召回率。教育版额外检查辅助限定和状态更新。
- [Tutor CoPilot §4–6](https://arxiv.org/html/2410.03017v2)：随机分配、预先确定结局和意向治疗思路；即时效果与长期成绩分开。迁移到计算机课程需无辅助前测、分层随机及预先指定协变量，并检查独立变式后测、延迟保持与迁移。

正式运行前冻结主要假设、主要比较、最小有意义效应、样本量依据、预算、版本、评价规则与统计方法。离线按任务族配对和聚类，学生试验按分配层级分析；零结果与失败分层完整保留。教师评审、模型评审和真实学习成绩分别报告。

## 工程优先级与验收条件

### P0 统一能力资格和声明类型

普通 reducer 不以多次普通成功升级稳定掌握；复习稳定门要求间隔和变式。Worker 在候选校验时对 `stable_mastery` 主要检查两个 verified Event，虽降格文本，仍保留该类型与谓词（`memory_worker.py:219`、`:487`）。同一关卡不同普通概念题独立答对可产生 verified Fact 并触发合成；因此在线模型若提出该候选，存在类型语义不一致的条件路径。这是静态风险，尚未端到端复现，不等于直接改变 KernelState 掌握；离线确定性合成器生成 `record`，不能把该风险算作原实验已发生错误。

建议：把证据资格做成共享确定性函数，由 reducer、Worker、画像和消费者共用。区分一次验证、重复独立验证、间隔稳定和验证迁移；每种资格附证据与策略版本。先补定向回归：两道普通题、同题受助重做、间隔不足、合法变式、旧成功后的失败、模型伪称稳定。旧 Claim 保留历史，通过正式派生纠正事件更新当前视图；不直接重写既有事实。

### P1 统一主题身份与评估证据接口

`memory_graph.py:134` 的主题提取检查 `concept_id/concept/concept_name`，正式概念评分携带 `concept_key`；若没有其他主题字段会退到 checkpoint。应核对同一关卡的不同概念是否被意外聚合，再使规范 concept key 成为共同身份。未复现的数据污染不能先写成发生过的事故。

`memory_episode.py:17` 仅支持有限概念/练习评估，`:208` 及 `:224` 明确记录规范题目关系不可用。建议为复习、纠错变式和经过验证的项目产物提供版本化证据适配器。旧 v1 保持可读；缺失规范身份保持未知，禁止按文本相似或 ID 猜迁移关系。验收包括跨概念不误聚合、各入口同等字段、不同表示共用接口及双端一致性。

### P1 原话回溯与控制生命周期分离

`learning_runtime.py:294` 的教学控制路径和 `memory_graph.py:51`、`:198` 的排除规则应保留。补只读、带 scope 的原文回溯，并标注是控制、观察、自述或待确认；只有确需更新状态时才登记派生 EvidenceEvent。验收长原文、否定、限定、多次改口、控制到期及敏感字段隔离，同时检查过期指令不经摘要重新生效。

### P1 为最新适用评估预留最小证据

保留真实来源、事件时间、结果、辅助、任务角色、范围和未知项，再按需加入正文。若这些字段仍不足以支持动作，必须明确缺少哪项条件，不能把紧凑化当作新的安全保证。比较相同预算下失败/成功分层覆盖、过时、条件丢失和无动作；保留当前连续前缀策略作为对照。

### P2 稳定反馈请求身份与多消费者一致性

`api/memory.py:29` 的反馈请求没有稳定请求 ID，`:439` 以服务器当前时间参与事件幂等身份。建议引入可选 `client_feedback_id`，绑定 learner、claim 和载荷指纹；兼容旧客户端，补同请求重试、同键不同内容冲突、合法新请求和并发回归。

另外应在纠正后同时检查 Tutor、规划、复习和画像的当前版本、scope 与过期状态，并测量实际更新延迟。当前没有这项端到端量化证据，不能只凭保留版本就断言所有消费者实时一致。

## 实施顺序

先定向复现并修正 P0 资格一致性及主题身份，再建立共同证据接口和评测诊断，随后冻结新任务族开展等信息比较与逐核干预。最后完成教师评价，再决定真实学习试验。跨端共享改动需要同步注册表、实现、测试、版本与兼容说明；工程修正和新实验各自保留来源，不回写旧结果。
