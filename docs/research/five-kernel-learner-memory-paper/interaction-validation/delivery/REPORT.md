## 证据范围

本结果补充的是“正式业务对象怎样与五核形成、读取和约束教学决策”。路径确认改变Structure/Value，不自动创建LearningTask；复习延期与跳过是零核写入事件，实际判题事件才提供Knowledge/Practice证据。当前与过期Human控制会改变真实离线计划的时间/支持要求，Value优先级改变摘要，Structure锚点进入待执行学习步骤；不能把这些称为UI已自动导航或课程已全局重排。

所谓边界挑战仅指预先构造的时间、更新、来源和scope组合；没有从现实任务分布抽样，不能声称真实长尾覆盖率、罕见任务优势或模型泛化。所有确认、题目与响应都是合成环境，规则上的稳定正例不是实际记忆保持率或学习收益。没有教师盲评、学生实验、真实编程产物、自然语言泛化、跨端完整回归或UI/HTTP中间件端到端验证。原生概念与复习API缺少session参数，27条评估事件的session为空，已全部保留；路径API则是learner全局范围，不能据此宣称会话粒度隔离。
