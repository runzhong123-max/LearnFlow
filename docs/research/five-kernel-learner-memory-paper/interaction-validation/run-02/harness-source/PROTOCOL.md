# 五核与路径、复习工作台交互验证 v1

本研究核验业务对象与五核的真实交互，并补充作者构造的时间/状态边界挑战。14 个不同情境，不按模板复制扩大样本；不是学生样本、真实长尾频率分布或外部效度证明。产品基线 62fd197236c4852b93bdf4a835020f095f2e8bb1。全部生产代码与旧冻结实验只读。

执行前固定本协议、cases.json、驱动、校验器和实际核心/后端来源 SHA256；写入 freeze.json 后才执行第一个原生案例。每例独立内存 SQLite，顺序执行；不调用网络、模型或日常数据库。只直接创建 Learner、Project、Roadmap、Checkpoint、Session、ConceptQuestion 环境/题目。Attempt、ReviewSchedule、Event、Mutation、State、Fact 等只能由正式 API 函数或登记事件产生。任何失败原始记录保留，不按结果修改案例或生产代码。

路径使用现有确认/修订/归档 API。复习从正式 phase3.submit_concept 自动创建 ReviewSchedule 开始，通过 get_review_item 获取真实公开题面/版本，通过 submit_review_item 提交，并读 get_review_history、build_review_tutor_context；延期走 defer_review_item。每步保存公开业务返回、前后行数、真实业务行与五核投影。最终实际调用 build_five_kernel_context、scoped planner、compile_planning_guidance 与离线计划消费者。调用路由函数不等于 HTTP 中间件、认证浏览器或 UI 测试。

题目为固定可计算闭合选择题 len(range(3))，变式为 len(range(6))。题目元数据中的 validated 是作者依据 Python 计算答案预先确认的题型合同，不是 LLM 自证，也不是独立专家对迁移难度的验证。答题脚本只从公开题面提取固定表达式并用 Python len(range(n)) 计算，再定位公开选项；不读取产品私有答案决定响应。保留计算收据。题目/规则构造不能说明真实学习者已经掌握或迁移。

## 冻结情境

1. 路径确认、重复同请求、正文修订、归档同步改变 Structure/Value。
2. 初次正式判题产生唯一有来源复习计划，不升级稳定掌握。
3. 三周后仅查看到期题，不新增学习证据或掌握。
4. 延期只改变排期，重复请求幂等，不新建 Attempt 或掌握。
5–7. 实际复习的有助原题、独立原题、独立已验证变式，保留不同证据和间隔调整。
8. 多周独立原题复习缺少变式，不能达到稳定证据合同。
9. 两次独立复习跨度 14 天且包含变式，通过实际 API 验证稳定证据规则正例；不是现实保持率证据。
10. 缺失/跳过/不会分别处理，缺失拒绝、跳过无 Attempt，重复跳过幂等；不会保留 abstained 与检索缺口。
11. 复习重复提交重放相同 Attempt，不重复事件或计分。
12–13. 多周路径修订、旧返回请求、当前目标、过期/当前时间与支持请求、复习历史和当期异项目干扰共同出现。
14. 达到规则稳定后再次实际答错，当前工作台应降为无稳定证据；另以作者预声明的安全标准检查未限定的长期 stable 标记不继续有效。后一条可能揭示既有长期状态与当前工作台不一致，失败不以“历史”措辞隐去。

每例都注入同 learner 异项目的当前优先级干扰；目标上下文不得引用其正文或事件。另以其他 learner 读取目标 ReviewSchedule，必须拒绝。路径 API 是 learner 全局范围，不伪称它拥有项目/会话参数。原生概念/复习评估无 session 参数这一限制如实保存，不人工补齐。

## 判定与审计

独立校验器不导入产品 reducer、规划规则、稳定证据 helper 或旧实验 expected 函数。根据实际 Events、Attempts、Schedules、Mutations、Facts、所有权表和每步业务返回检查来源一致性，并执行预声明字段断言。稳定条件独立从原生 review events 计算：最后失败之后、通过且独立且合格的至少两次复习、跨度至少72小时、至少一个 validated_variant。分子是完整通过案例，分母固定14；每例所有先决来源门和特定断言均通过才算成功。空输出、部分形成、预期外拒绝不能得分。单列合同情境、作者边界挑战和作者安全挑战；不把后者称产品已承诺的回归保证。

不从 ReviewSchedule 到期时间、延期、用户自述、模型生成、计划完成或支持下成功推断掌握。不把小变式字段等同于真实迁移测量。教学控制原本不全部 Fact 化；核验其 Event/Mutation/State 通道。业务状态、知识状态、读取/展示状态分层报告；保留已有失败及完整证据，不能只报总通过率。

冻结后完成真实运行，重开保存的原始 JSONL 重新计算，验证来源不漂移和制品哈希。校验器负例/正例回归在执行前运行，不计入14个案例。时间是注入的 UTC 事件/业务时钟；ORM创建时间可能仍为实际系统时钟，不用于间隔判定。没有真实学生、教师盲评、自然语言泛化、UI端到端、检索大规模压力、真实长尾分布、模型比较或跨宿主完整回归。
