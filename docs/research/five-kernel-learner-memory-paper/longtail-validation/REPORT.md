## 解释边界

- source 同时扩大最多 4096 条候选扫描、改变原文和元数据预算，不能将差异独归于分段。
- alias/fuzzy/temporal 只在对应情境关闭；它们是同一生产策略的组件消融，包含该组件候选与排序的整体作用。候选集合是否相同另列，不能假称固定池。
- 词表外表达和歧义词保留失败；强匹配异 learner/project/checkpoint 原文均为污染负控。
- 当前 KernelState 只保留有界历史回执，旧回执淘汰不等于历史 Fact 形成失败；核验完整持久化 mutation 版本序列。
- 这些情况是定向压力条件，不估计真实教育人群的长尾发生率；256 条干扰只是有界数据库历史压力，不证明任意长历史。
