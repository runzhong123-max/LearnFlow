## 项目字段

- 项目类型：`做一个作品或实验`
- 项目主题：`Serverless 图片处理流水线：对象存储、队列与函数重试`
- 学习目标：理解对象存储事件、消息队列、函数触发器、可见性超时和重试；设计一个上传图片后异步生成缩略图且不会因重复消息产生错误结果的流程。
