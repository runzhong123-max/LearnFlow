# 桌面项目：以对话串联关卡与原子文件

2026-09-13。正式桌面入口为 `apps/desktop/frontend/src/ProjectWorkspacePage.tsx`，覆盖本地与云账号项目。Web 原有项目对话入口不变。

项目和关卡的正式 Tutor 会话占据主区域，默认没有阶段导航、任务仪表盘和窄导师栏。顶部按需打开关卡图、资料、文件；辅助面板在宽屏并排，在窄屏覆盖右侧，关闭或 Escape 返回完整对话。关卡与交付、旧思考纸和案例初始化从更多菜单访问。原本的本地运行工具从文件面板展开。

讲义、练习生成后作为真实工具结果留在当前关卡对话，点击复用既有受管纸张。文件管理中新建或选择的原子文件通过已登记的 scoped 文件 API 成功读取后，才产生带路径与版本的结果卡。工程助手经确认写回后也把实际改动文件回送为卡片。相同文件版本不重复插入卡片；点击在该正式对话里复用路径对应的代码纸张。历史带行范围的 `workspace_file` 引用仍按选区追问呈现。

代码纸读取真实文件，维护单文件编辑草稿和基础 hash，显式保存沿原文件服务执行。切换纸张或项目时，本次应用运行内的代码草稿保留；刷新或退出有未保存提醒，未承诺崩溃恢复。冲突时保留草稿并拒绝覆盖，二进制和受保护文件不可编辑。已保存文件可加入关卡交付；云端明确分享摘要，源码不随交付上传。

四档帮助为给方向、拆步骤、看伪代码、完整代码。先调用已有 assistance API 记录帮助程度，再将用户选择的文件内容与请求交给同一 Tutor。完整代码是参考实现，用户核对后保存；不宣称模型已落盘。真实 Broker 改动继续走既有两次确认。帮助与交付返回的 workflow 同步回当前项目视图，避免本页面使用过期 revision。

Contract impact：桌面 registry `2026-09-13.6-desktop` 增量登记 `project_code_paper` 展示入口，复用现有 `inspect_workspace_files`、文件写入、帮助和交付能力。`TutorToolRun.workspaceFile` 为可选显示元数据；旧对话仍可读取。未新增主 Agent、API、EvidenceEvent、五核字段或数据库迁移；不改变掌握与评分规则。文件读写与帮助沿既有事件链，结果卡和纸张布局本身不是学习证据。

验收：项目默认展示正式对话；资料面板直达来源管理；关卡图切换正确的 Session；文件卡可重复打开；代码草稿跨纸张保留；磁盘冲突拒绝覆盖；帮助先保存再请求 Tutor；未选择关卡或关卡锁定时禁止帮助升级；交付依然通过正式反馈入口核对。UI fixture 使用隔离假数据，不读写日常数据库，不调用在线模型。

本轮验证：桌面前端完整测试 581 项通过；桌面后端 1170 项通过、5 项按现有环境条件跳过；另执行生产构建、共享契约检查、diff 检查与隔离浏览器 UI 流程。UI 检查包含对话草稿隔离、结果卡到代码纸、草稿返回、hash 保存及冲突保护、帮助记录和窄屏边界；在线模型生成及真实 Broker 运行未执行。
