# 对话可视化来源选择与恢复

2026-09-08，Web / desktop registry .7；现有 educational_visuals 与 visual_teaching_composition 的内部修复。

线上哈夫曼任务已有主题和两份维护库命中，却生成 SVGStory；候选 steps 带额外 id，被严格字段集合拒绝。泛化错误 `svg_story:step fields` 使有限修复没有明确目标。

- 有候选且没有明确 fresh 时，先给模型简短来源选择契约，仅包含作品元数据、请求与有界上下文。正确匹配优先复用；具体输入不匹配不能谎称已演示。interactive_html 保持精确版本原样复用。无命中或明确 fresh 直接构建。
- 来源选择结果与原始候选继续检查点持久化。生成完整 source 的既有响应仍兼容。模型决定新建时需给明确原因，下一步才接收完整构建 DSL。
- SVGStory v1 增量接受可选且合法、唯一的步骤 id；原样保留 source，不修改用户数据。运行版本 1.0.2。未知字段、缺失字段和错误引用返回具体步骤路径。旧版无 id 规格继续可用。
- 每次调用仍最多一次修复；暂停写入最新诊断，恢复优先处理已保存 source。不能用 SVG 绕过数值验证，不能把作品操作当成掌握证据。

Contract impact：现有 SVGStory v1 增量兼容可选步骤元数据；Job route 新增可选 routing_decided，无数据库迁移，无主 Agent、五核或事件语义变更。两端消费同一共享实现。

验收覆盖来源选择/构建分离、哈夫曼检索作品原样复用、明确 fresh、断点恢复、最新诊断、步骤 ID 与错误引用校验。模型选择测试使用固定响应，只验证工作流契约，不代表所有在线模型一定选对。
