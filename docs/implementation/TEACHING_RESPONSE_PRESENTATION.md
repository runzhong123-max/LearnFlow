# Tutor 教学表达 v1

## 目标与实际范围

让学生扫读取得答案，细读理解机制，并从同一机制得到一个有用推论。普通解释先回答当前疑问，按需展开机制、贯穿例子和边界；局部追问只补卡点。公式、代码、表格和已生成的视觉产物必须与文字中的同一例子对应。

本版接入浏览器 Agent 回合、浏览器直接生成与正式后端 Tutor（包含纯文本兼容回复）。复用当前 Markdown、KaTeX 和工具产物展示；没有新增可执行代码页面、交互组件或富内容消息 schema。没有额外模型评审调用，不额外执行学生代码。自然语言质量仍需用真实模型与使用反馈检验。

## 单一来源与调用路径

- 注册表：`DATA_CONTRACTS.teaching_response_v1`，owner 为 `tutor_agent`，版本为 `learnflow-teaching-response/v1`。
- 权威文案：`backend/app/contracts/teaching-response.v1.json`，包含稳定规则和三个短写作示例。
- 后端：`teaching_response_prompt()` 在正式 Tutor 的 system 前缀装配；现有 JSON schema 仍然有效，表达规范只作用于 `reply`。
- 浏览器：`frontend/src/generated/teaching-response-policy.json` 是确定性导出，`systemPrompt()` 统一注入。Agent runtime、直接生成和视觉独立讲解共同继承它。
- 动态学习者事实仍走既有有 scope 的上下文与即时教学指导，不复制进静态政策，不额外建立用户画像。

更新文案后运行：

```bash
backend/venv/bin/python backend/scripts/export_teaching_response_policy.py
backend/venv/bin/python backend/scripts/export_teaching_response_policy.py --check
```

前端产物随源码提交，前端独立容器构建不需要 Python 或后端源目录。后端测试校验导出逐字段一致，防止两端长期漂移。文案含义发生实质改变时维护契约版本、生成文件、样例和相关回归。

## 表达与元素规则

| 场景 | 默认表达 | 边界 |
| --- | --- | --- |
| 概念 | 直接定义与具体作用 | 一句话请求不扩展成长讲义 |
| 机制 | 条件、动作、结果与贯穿实例 | 不把术语清单当解释 |
| 比较 | 差异如何影响选择 | 不机械罗列全部属性 |
| 操作 | 最短做法与结果检查 | 不声称未执行的代码已验证 |
| 卡点 | 只补这一处，必要时换表征 | 不重复整章或推断人格/固定能力 |
| 公式 | 符号、条件、代入或推导 | 使用 `$...$` 与独占行的 `$$`，JSON 正确转义 |
| 代码 | 带语言的围栏、关键行、输入输出 | 保留换行与缩进 |
| 图解/动画 | 引入观察目标，引用实际产物 | 仍需显式视觉请求与既有工具门，不虚构画面或按钮 |

普通解释不默认附加自检题或下一步菜单。正式 SkillRun 要求提问、练习、答案隔离时，仍以当前动作作为硬边界。表达规范不能改变评分、教学策略、阶段、完成门或掌握状态。

岗位插件正文使用对象名称和自然关系。稳定 ID、快照、原始关系与证据仍完整保存在工具结果、对象引用和宿主详情中；事实归因和候选/推断等语义必须保留。研究原始协议的明确请求可以展示必要标识。

视觉独立讲解的 Markdown 不再经过压平空白的 label 清洗。大于 5000 字符的讲解明确报错并进入既有修复/失败路径，不能从中间截断代码或公式。已提交讲解在后续 Brief 失败或渲染失败时保持原有换行。

## 验证与反馈素材

`backend/tests/fixtures/teaching_response_cases.json` 保存 20 个模拟问题、参考回答和审查要点。其中连续追问携带必要的前文，不把完整样例库每轮塞进模型上下文。

自动化覆盖：

- 两种 provider 协议下，20 个参考回答通过真实回合编排后的文字/公式/代码保真，以及原始对话历史保留。
- 四种模式都继承同一表达前缀，正式步骤与工具边界仍存在。
- 正式后端的首个模型调用和最终 API 回复包含规范并保留 Markdown。
- 真实 Markdown/KaTeX 库渲染公式、代码缩进和表格；代码内美元符号不当作公式。
- 视觉讲解经过 Brief 与失败终态仍保留格式；过长输入不静默截断。
- 岗位插件的自然语言表达规则不删除追溯和关系方向约束。
- 注册表绑定、前后端文案导出漂移、现有 Tutor 与视觉回归。

参考回答由同一模型设计；provider 在集成测试中是 stub。这些用例证明接线与格式保真，不构成回答质量提升、学生偏好或学习效果的实证。真实反馈优先记录完整问题、前两轮上下文、实际回答以及具体卡点；下一轮可在同模型同配置下匿名比较实际生成结果。
