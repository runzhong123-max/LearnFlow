# 网页学习规划资料工作台

网页端学习规划对话显示资料工作台：推荐候选、手动 URL、本地上传、已接入资料、后续关卡与长期计划。桌面入口本轮不启用。

- 推荐按钮由学习者触发 Tutor 读取来源、检索书籍/仓库/官方文档并解释取舍。卡片只消费已完成 ToolRun 的真实 HTTP(S) 来源，不从模型正文解析或虚构链接；未核验的许可与片段状态如实展示。
- 学习者逐项选择，项目对话复用项目来源上传/处理 API，普通对话复用个人资料库 API。资料处理失败保留错误与重试，不假称入库成功。正式来源保存在后端，重新打开时重读。
- 有已处理来源后可请求关卡或长期计划。项目 Tutor 固定当前项目、已有目标、来源与不可改动的已开始关卡；普通对话比较方向、阅读负担与长期阶段，不能冒充已建项目。
- 计划按钮提交可见用户请求，不自动接受模型提案。现有路线提案与显式确认继续负责写入。
- 实验和实践在资料选择后提出，每个实验应关联实际章节/仓库文件、环境成本、输入、可观察结果和检查方式；未读内容不虚构章节。

验收：运行 planning-resources、planning、agent-runtime 回归，Web 构建及后端架构注册检查。浏览器以隔离模拟身份验证资料选择、上传、错误呈现、刷新恢复和模式差异；模拟验证不代表外部搜索或模型推荐质量已通过在线评估。
