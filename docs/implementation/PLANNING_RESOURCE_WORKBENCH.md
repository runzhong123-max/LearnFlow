# 网页学习规划资料工作台

网页端学习规划的输入框“＋”菜单提供“推荐书籍与仓库”。调用沿用 Tutor 的现有来源读取和检索工具，推荐资料面板作为该轮助手消息中的可展开工具结果出现，不再常驻输入框上方。用户也可直接在对话中提出推荐请求。桌面入口本轮不启用。

- 每张推荐工具卡仅消费所属消息的搜索/网页读取 ToolRun，不混入其他轮次候选。检索中、失败和空结果如实显示，失败后可以重新推荐或手动添加资料。
- 展开工具卡后才读取资料库，保留 URL、本地上传、候选选择、已接入资料、关卡与长期计划操作；折叠不丢弃正在进行的保存操作。历史消息根据持久化 ToolRun 恢复候选，不额外保存一份推荐状态。

- 推荐按钮由学习者触发 Tutor 读取来源、检索书籍/仓库/官方文档并解释取舍。卡片只消费已完成 ToolRun 的真实 HTTP(S) 来源，不从模型正文解析或虚构链接；未核验的许可与片段状态如实展示。
- 学习者逐项选择，项目对话复用项目来源上传/处理 API，普通对话复用个人资料库 API。资料处理失败保留错误与重试，不假称入库成功。正式来源保存在后端，重新打开时重读。
- 有已处理来源后可请求关卡或长期计划。项目 Tutor 固定当前项目、已有目标、来源与不可改动的已开始关卡；普通对话比较方向、阅读负担与长期阶段，不能冒充已建项目。
- 计划按钮提交可见用户请求，不自动接受模型提案。现有路线提案与显式确认继续负责写入。
- 实验和实践在资料选择后提出，每个实验应关联实际章节/仓库文件、环境成本、输入、可观察结果和检查方式；未读内容不虚构章节。

Contract impact：注册表 2026-09-09.1 增加既有 source_ingestion 的前端实现绑定。稳定能力、事件、五核写入链和数据 schema 不变；无数据迁移，不引入第二份持久画像。

验收：运行 planning-resources、planning、agent-runtime 回归，Web 构建及后端架构注册检查。浏览器以隔离模拟身份验证资料选择、上传、错误呈现、刷新恢复和模式差异；模拟验证不代表外部搜索或模型推荐质量已通过在线评估。

## 2026-09-14 规划对话入口与工具批次修复

项目列表的“对话规划学习”直接建立学习规划模式的普通对话，沿既有会话持久化，不提前建立项目。规划 Agent 在目标明确而资料不足时主动使用现有 search_computer_knowledge / read_web_evidence，推荐结果沿原 ToolRun 卡片展示。正式图谱已定位时仍允许以教材、书籍、文档或仓库为目标的检索；已有资料和时间微调应复用结果。

模型同轮工具调用必须先全部返回对应结果，再插入搜索后的个人节点提案。预算拒绝也返回对应工具结果；最终收束保留完整有界消息链，不能按消息条数截出孤立工具结果。

Contract impact：无新能力、事件、schema、五核语义或数据库变化，复用已登记规划、来源工具和项目工作台入口。本轮仅网页前端与 Node Tutor 实现变更。

本轮验证：规划、资料卡片与 Agent Runtime 76 项回归通过；架构注册 28 项通过；Web 构建与 diff 检查通过。Playwright 使用隔离模拟认证验证项目页按钮跳转、规划欢迎语与模式选择器；未连接真实模型或日常数据库，不代表线上供应商与推荐质量已验收。

推荐列表可见性优化：外层提供显式查看/收起入口，候选与资料库标题显示箭头及展开/收起文字。候选默认展开，不因已加载资料库非空而关闭；每项显示课程/教材/仓库类型，并提供独立“打开资料”链接和选择按钮。移除双层内部滚动，复用原资料保存与确认流程。Web 构建、4 项资料回归及隔离浏览器已有资料场景通过；无契约或数据库变更。

## 资料简介、咨询与选用

每张候选卡分开展示来源摘要、推荐理由和核验范围；没有摘要时明确提示缺失，不推断基础、时长或语言。Tutor 规划指令要求先阅读资料、介绍覆盖与适用条件，未知项如实说明。勾选用于咨询，用户可以填写问题并比较多份资料，也可以直接询问单份资料；提交沿既有可见对话入口，携带真实工具结果的精确 URL，不自动入库。

“确认选用”复用正式来源添加与处理 API。卡片高亮、顶部本轮已选清单、保存提示和资料库处理状态共同表达选择结果；失败与隔离不算可用于规划。已选名称通过正式来源 URL 与同一对话持久化 ToolRun 标题对应，页面刷新仍可恢复；原始来源和个人文件名不改写。规划按钮附带已处理来源 ID、名称及 URL，不把临时勾选作为选用结果。

Contract impact：复用既有规划、资料读取和接入能力，无新事件、schema、五核语义或数据库变化。79 项相关回归与 Web 构建通过；隔离浏览器验证多选咨询零写入、单次确认保存/处理、刷新恢复及计划引用。未进行线上真实模型简介质量评估。本次临时咨询勾选和问题草稿不跨刷新保存。

推荐理由展示修正：SearchSource.reason 当前是检索来源/证据用途说明，不是针对学习者的推荐依据。资料卡移除整个“推荐理由”栏及空值占位，仅保留来源简介和核验范围；具体选择建议仍在 Tutor 咨询中结合目标和资料回答。旧持久化 ToolRun 同样按此展示，无数据迁移或契约变化。
