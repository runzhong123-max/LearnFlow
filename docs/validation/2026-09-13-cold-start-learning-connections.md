# 冷启动知识技能连接闭环

用户要求：完整冷启动包含能力/单元—知识技能—学习路径连接，取消独立挂载面板与手动预览步骤；已有课程优先复用，岗位语义附在学习节点上。

## 实现与边界

- 新增已有研究流程内部的支撑关系推导：使用同一模型预算与复核预算；本地核对节点和逐字引用，独立原文复核通过后写候选推断边与依据。未获支持的边不写入。
- 内容完成检查覆盖能力单元归属、知识技能支撑、分类、范围、可观察要求与依据，拒绝悬空/已拒绝/无关关系。提交时重算，检查点不能以旧 ready 绕过。
- 已有自动连接事务、身份与固定版本回执继续复用；用户无需执行额外挂载步骤。内容就绪与路径连接均完成后，界面才显示全流程完成。
- 删除独立挂载面板；路径身份及岗位应用语义在节点详情查看。无当前回执的知识技能不再从图谱数据删除，旧回执不覆盖新快照。
- 草稿终止显示待补全，不再谎报后台还在运行。

Contract impact：无对外 schema 或事件语义变化，沿用注册的 role_research_run_v2 和 curriculum_source_runtime；无五核写入或数据库迁移。已停止的旧研究不会因代码上线自动补造内容或重置预算。
