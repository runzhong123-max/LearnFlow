# 可检查学习记忆与当前复习资格：升级及验收

本次实现提交：`23fcb414c8baa03254defe0cbc82c4fd27ae4179`（本地 main）。共享核心 0.2.7，Web 注册表 2026-09-13.5，桌面注册表 2026-09-13.5-desktop。本轮未推送、未部署、未迁移日常数据库。

## 已实现的能力

- 画像 `/learner-profile`、画像声明与复习 `/review` 使用共享来源卡片。支持来源片段、Fact 正文哈希与字符范围、事件和变更编号、辅助程度、独立性、题目形式及结果；原始结构化记录默认折叠。
- 卡片可以沿实际记录的证据关系双向查看、回溯与翻页。每卡来源上限 20、关联上限 40；缺失、损坏、越权或截断不伪装成完整来源。
- 初次正式作答已经形成复习任务、但尚无复习尝试时，也能查看初始评估依据。
- 复习失败撤销知识核与实践核的当前稳定资格；旧成功事件、Attempt 与事实正文保留。旧短期保持状态和长期资格快照、依赖它们的 Module/Claim 不再作为当前结论使用。后续须重新通过原有间隔与独立变式规则才能恢复。
- 旧库通过只读保护排除失效 stable；不直接写 KernelState。新 Fact 按当前题目投影；无法完整归属当前题目的旧聚合包不作为该题的可核对来源。

**Contract impact**：`review-qualification.v2` 有意收紧 stable 的当前适用语义，增添资格、历史依据和失效事件字段。评分规则不变，事件写入链不变，无新数据库或并列画像。详细兼容性见[实现说明](../implementation/MEMORY_EVIDENCE_WORKBENCH.md)。

## 保留的限制与失败记录

- 这是解释性与状态正确性的工程升级。14 个场景是作者设计的业务验证，不是真实教育人群、学习增益实验或全面长尾消融。原论文的长尾检索成绩、传统记忆基线排名均未因此更新。
- 只展示已记录的关系，没有追踪每一次路径、计划和 Agent 对证据的消费；没有接入 Obsidian 插件、文件同步或完整知识图谱编辑器。
- 旧聚合包无法安全按题归属时显示覆盖缺口，保留历史原件而不拼造来源。只读 guard 仍扫描本学习者的相关历史，尚无大规模延迟基准。
- 冷启动首次浏览时出现过 `kernel_heads.learner_id, kernel_heads.kernel_name` 唯一约束冲突，引起既有画像/复习初始化接口 500；刷新后恢复。它涉及现存 KernelHead 并发初始化，本轮未修改该路径，不能声称所有冷启动问题已解决。新增来源接口本身不初始化 KernelHead。
- 直接 `bash start.sh demo` 未执行，以隔离临时库、显式本机端口和相同 seeded 数据完成核心页面与验收接口检查，避免影响正在使用的环境。没有用户日常数据库被用于实验。

初次针对性回归曾因旧 stable 预期失败，前端初次构建曾因 ES2020 不支持 Array.at 失败；修正后重新通过。旧结果和开发阶段记录都保留，不以最终通过抹掉过程失败。
