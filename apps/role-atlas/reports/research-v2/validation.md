# Role Atlas 冷启动与迭代重构验收记录

日期：2026-09-12。范围：本地代码、离线回归、已知公开来源和真实模型机制验收。未推送、部署、迁移日常数据库或替换用户应用。

## 实现结果

- 新请求使用 `role-research/v2`。冷启动与迭代共用研究主管、调查员、独立复核、共享来源、会话检查点和预算账本；历史请求继续原协议恢复。
- 主管可以提出已有工作项之外的问题，读取来源、局部图谱和研究记录，提交候选改动。调查允许访问相邻岗位背景，改动权限独立受作用域校验约束。
- 原生多轮工具调用保存供应商会话字段、调用 ID、usage 和完整结果。资料索引、正文、图谱关系和归档结果均有续读位置。调用前保存预算预占，失败与恢复不重置账本。
- `ResearchIntent / Agenda / Task / Finding / ChangeSet / Run` 统一承载新运行。去掉虚假 dependencies 调度；风险和雷达读取发现记录。重复发现不当作新进展，反证和适用情境变化可计入。
- 核心任务具备目标、触发、输入、责任、活动、交付物、质量要求及知识能力过程衔接后，才可能交付完整首版；否则保留草稿与缺口；没有正式版本时工作台可以读取同项目草稿，用户显式续研可复用全部来源及长正文。企业材料缺失明确留给下游。
- 候选改动固定基线，支持新增、修订、补证、拆分、合并、替代和废弃。原子编译、引用检查、独立复核和产品质量判定分开执行。低影响修订只有实际替换文本得到复核支持且质量检查通过，才能默认自动采用；身份迁移和未解决语义问题进入审阅。既有版本回退和 Hub 发布机制保留。
- 任务详情与研究记录分层展示；界面提供目标、对象、深度和采用方式。任务详情带表达性质、引用、复核及下游缺口。

## Contract impact

新增研究协议 `role-research/v2`、任务定义 `role-task-definition/v1` 和岗位包 `3.1.0`。Web 与桌面导入端继续接受 `2.0.0`、`3.0.0`，不补造旧包字段、不改变旧包哈希。下游仍通过 packageId、packageVersion、snapshotId、rootHash 和任务 ID 定位；launch 不塞入整个正文。

根注册表版本 `2026-09-12.1`，桌面注册表 `2026-09-12.1-desktop`。岗位生产是 Role Atlas 的运行契约，复用既有后台任务入口；没有给 LearnFlow 添加岗位生产工具或第四类主 Agent。三类主 Agent、五核、148 个共享事件和学习状态写入链保持原语义。

## 真实模型与网络验收

可复现命令（在 apps/role-atlas 目录，凭据仅从环境变量读取）：

```bash
node --import tsx scripts/verify-research-v2-live.ts
node --import tsx scripts/verify-research-v2-orchestration.ts
```

DeepSeek 原生连通性：2 次交互、1 次工具调用，实际 usage 共 1531 token；读取已知官方 Tool Calls 页面成功。MiMo 的 SSE 参数拼接、调用 ID、结束原因和供应商字段通过离线测试。

真实三角色链路使用已标 public 的静态发布包，严格限于政府公开《职业分类大典》的三个既有转述片段。1 个独立问题、15 次工具调用、62 次检查点回调，规划调查 52770 token，独立复核 2363 token，共 55133 token；没有新的网络搜索。6 条最终判断中 4 条得到复核支持，2 条保持未验证。支持判定不是事实证明；这些测试输出没有采用为岗位版本。

机器可读摘要见 [live-check-summary.json](live-check-summary.json)。完整临时执行输出保存在本机 `/private/tmp/role-research-v2-*.json`，不提交原始模型日志和凭据。

## 发现、修正与复验

首次全量测试发现注册表测试仍断言旧版本号，已同步并重新运行两端全量回归。资料索引工具加入后，旧工具清单断言已更新并补充续读行为回归。

真实链路首次运行暴露复核输出格式未明确的问题：研究成功但复核解析失败，候选保持未判断。补齐明确的 verdicts / claimId / verdict / note 协议后复验通过，没有通过降低事实门槛让测试过关。

最初包含冻结材料的外发测试被自动审批拒绝。随后先核实 manifest 的 public 标记、政府公开来源及具体三个片段，再限定脚本输入并通过自动审批。私有底稿、审核记录、历史对话和日常数据库未外发。

另修复结构化工具被旧参数表误拒、相邻资料被旧岗位过滤误拦、转述被当作原话、低影响修订未进入迭代采用判定、重复发现被计为进展、旧 API 字段限制导致新预算排队失败、首版草稿刷新后无法复用等问题，并加入回归。

## 未执行与效果边界

- MiMo 真实网络模型调用未执行：环境没有 MiMo 凭据。离线协议测试不能替代真实供应商验收。
- 未在日常项目库上启动完整应用并执行大预算冷启动；运行机制由隔离测试和冻结公开材料的真实小规模链路验证。
- 未新增教师或学生人工评测。既有人工审核记录仅作为冻结基线；本轮工程表达检查、内容审阅和浏览器验证不能证明学生实际理解提升。
- 没有开展新的具体岗位调研，也没有验证企业真实材料的项目转换效果。下游转换引擎、实践执行与五核本轮未重写。
- 两端后端存在既有 Pydantic / datetime 弃用警告，前端构建有包体积提示，Role Atlas 有 vinext 静态路由分类提示；本轮构建与测试没有因此失败。
