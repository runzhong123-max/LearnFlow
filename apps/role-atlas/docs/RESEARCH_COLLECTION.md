# 测试数据中心 · role-research-archive/v1

管理员从 Role Atlas 侧栏进入独立 `/admin/research`。测试员名称来自已验证的身份桥接，仅作历史署名，不参与授权。按用户/项目与冷启动、迭代/深化、工作区接入、风险检查分类，查看实际输入、选项、资料、调用、状态、候选及发布。支持原件、单轮、类别、项目及一键全量 ZIP 导出；设计面向离线分析，不提供批量改图、重新运行或自动训练按钮。

## 管理员查看用户

页面默认展示全部用户（含已回收项目），明确标注完整 `owner_subject_id` 为“用户 ID”，名称与项目 ID 分行展示。用户下拉框按完整主体 ID 精确筛选项目与附件；搜索支持项目、附件名、用户 ID 和已记录测试员名称。用户选项来自项目与附件预览中实际存在的主体，不代表全站注册账户数。历史缺失主体保留“历史未归属”，不按名称猜测或迁移归属。

列表筛选只影响页面展示；“一键导出全部”仍导出全部用户数据，项目/本轮/类别导出沿用选中的明确范围。接口既有管理员全局只读范围与普通用户项目隔离不变，导出的项目元数据保留原始主体 ID。

## 数据与权限

- `/api/admin/research`、`/api/admin/research/export` 均先通过 LearnFlow `/api/auth/me` 验证 `role=admin`，再读库。用户名、前端状态、请求参数不能授予管理员权限。所有响应 private/no-store；管理员读取、导出进入 `research_admin_events`。
- `/api/research-materials` 使用已验证普通账户，按主体保存原件。文件最长 5 MB，流式请求最大 6 MB，支持 PDF/DOCX/TXT/MD/CSV/JSON。解析正文或失败原因与原件一起保留；原件不作为已提交资料自动进入研究。运行认领时校验附件主体与项目主体一致再建立引用。
- 新附件按 SHA-256 分块存入既有 D1 持久卷，避免依赖额外对象存储。每个主体存档额度 200 MB；相同主体、文件名与字节幂等。文件原件保持原始字节，不声称已脱敏。模型配置/API 密钥、鉴权头、Cookie 不采集；结构化导出递归删除已识别凭据。
- 模型调用在实际执行前记录 system/user、模型、thinking、参数、输入哈希、代码版本（可用时）；结束记录输出、推理通道、耗时、错误、完成/失败/取消。单字段 160000 字符上限，明确截断和原长度；当前 adapter 未提供 usage，记录 null。采集失败使本次调用失败，避免伪称已有完整记录。重试保留独立调用 ID。
- 冷启动快速/完整阶段、自动深研/修复、用户迭代与工作区后续迭代使用各自 run ID。普通讲解对话沿用既有 messages 历史，本功能不扩大成所有聊天模型调用采集。
- 每次执行租约的实际输入、基线和结束状态进入 `research_run_attempts`，同一 run ID 重试也保留不同 attempt 的输入。运行中断时保留最后已归档状态；导出同时附当前 job，不能将旧 attempt 的 running 当作仍在执行。
- 原始运行表与不可变 project_versions 是历史权威；新增 schema 在 `lib/research-collection/schema.ts`，由 `collectionDb()` 幂等初始化。无旧表删除或数据迁移，无新五核、掌握判定、第四类 Agent。后台运维审计不进入学习 EvidenceEvent 链。

## 分析包

ZIP 中 `projects/<id>/project.json` 为索引；`runs/<kind>-<id>` 包含输入、完整提交参数、事件、实际模型调用、检查点与结果。`versions`、`base-versions`（单轮）、`diffs`、`version-events` 区分基线、候选与采用。`releases` 与 `release-events` 区分生成、校验、发布。所有项目导出包含对话/messages；附件原件及元数据、引用关系位于 `attachments` 与 `attachment-links`。未提交及解析失败的原件也纳入全量导出。

`manifest.json` 记录 schemaVersion、scope、文件字节数与 SHA-256、错误和 complete。导出流按消费速度继续读取；最多 512 MB 未压缩内容，超限或读取失败仍关闭 ZIP 并标记 complete=false，需按项目拆分。运行中的导出是逐项观察值，并非跨表事务快照。导出不会修改运行/项目状态。历史没有采集的原件或模型调用无法补回，空记录不能推断未使用；候选内容不能推断已采用或已发布。

记录随 Role Atlas `.wrangler` 数据卷备份。当前无自动清理；采集表中的引用有意不随项目回收级联删除，管理员应按测试资料保留规则管理备份和分析包。此版本不新建公共分享链接，不自动把私人测试资料发送给模型分析。
