# 典型任务页的信息层级

2026-09-13：典型任务页在项目与研究对话之间采用单列阅读布局。

- 顶部横向任务目录只展示编号和名称，选中项自动进入可视区域；切换任务时正文回到顶部。
- 正文先呈现任务名称、研究状态与工作说明。旧摘要只有包含完整的“对象、交付、完成标准”标记后缀时才拆行展示，不推断缺失字段。
- “转为学习任务”为主操作，证据与引用为次操作；置信度、关系数量与转换说明放在可展开的研究依据中。
- “能力要求”默认展示可阅读清单；雷达按需展开。窄屏保留能力清单和引用入口，雷达允许独立横向滚动。
- “工作过程”沿用现有事理流程组件；当前任务没有场景时，明确提示待补充，并可引用任务到研究对话。

Contract impact：仅调整现有工作台的前端组织和文案。稳定节点 ID、relations/process URL 参数、证据、引用和学习任务转换接口保持兼容；不增加能力或写入事件。

验收：任务直链、任务切换、能力/过程切换、雷达展开、窄屏清单、无场景状态；自动化覆盖摘要保留与场景隔离。使用内置只读示例做浏览器验证，不修改真实项目数据。
