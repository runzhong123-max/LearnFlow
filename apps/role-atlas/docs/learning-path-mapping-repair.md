# 学习路径挂载入口修复

本次恢复既有只读路径投影和 LearnFlow 源图预览、提交入口，不新增 API、岗位生成协议、主 Agent 或学习事件。

- 对话中的冷启动与迭代共用官方静态路径读取。读取失败或准备阶段取消时不提交任务，不把缺失路径静默当成对齐成功。
- 岗位工作台区分名称匹配、相近候选、待消歧和缺少锚点。v1 投影不是当前用户已保存的源图，名称匹配也不是语义等价或入库回执。混合条目、缺少定义或验收条件的条目明确显示待完善。
- 正式挂载只对当前对话的精确项目版本开放。先读取已校验的对应 Release，再核对导出 manifest 的项目版本、快照、包版本和 rootHash。找不到时提供准备私有岗位包的入口，不替换成另一个快照，也不自动发布。
- LearnFlow `/ecosystem` 默认展示可交互挂载页面。URL 携带 `packageId/packageVersion/snapshotId/rootHash` 和可选 `nodeId`；不完整、重复或不存在的节点标识明确失败。工作区规范化 URL 时保留这些参数。打开链接只读取包，不自动调用 resolve 或 commit。
- 用户点击预览后继续复用主体隔离的 v2 resolve；用户点击应用才调用既有 commit。Graph Hub 仍由明确外链在新标签页打开，不因恢复工作区标签而导航整站。

桌面当前没有这套 Ecosystem 页面或客户端的同实现，本次不复制一个中央账号工作台到本地身份入口。Role Atlas 链接进入中央 LearnFlow 网页，仍由该端登录和既有服务验证主体与固定包权限。

定向回归覆盖：URL 完整四元身份、节点不回退、路由参数保留、v1 状态不宣称入库、精确项目版本制品选择、静态路径读取失败及取消。已有 v2 解析、幂等提交、并发版本拒绝、零五核写入测试继续适用。
