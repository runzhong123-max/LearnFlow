# 冷启动与迭代功能审计及修复

本轮依据《岗位包测试报告》、实际测试项目的只读运行记录以及页面执行链审查。重点是按钮所表示的动作是否真实执行，不用节点数量或绿色完成状态代替结果质量。

## 已确认的问题与修复

| 页面/功能 | 原行为与影响 | 修复 |
| --- | --- | --- |
| 带资料冷启动 | 复用来源时直接关闭搜索；材料没有用于生成聚焦查询 | 联网开关独立控制搜索，复用资料不关闭研究；材料技术词用于补充中英文查询，仍保留独立职责/实践检索 |
| 项目名称 | `数据工程师-岗位资料QA` 等测试标记原样进入查询 | 仅去除明确分隔的测试标记，保留实际 QA、软件测试岗位名与专业方向 |
| 来源资格 | 英文官方文档无知识证据角色；技术检索找到的招聘页因分类不符被排除 | 按正文确认职责、技术、教学等证据角色；技术文档不能单独证明岗位责任 |
| 搜索相关性 | 通用“应用工程师”后缀让 BIM 等相邻岗位进入候选；纯英文技术文档缺少中文岗位名而被排除 | 加权岗位专有部分；一手文档可通过实际技术查询中的独特技术词进入研究，通用 API/docs 匹配无效 |
| 空任务冷启动 | 只有岗位根节点仍按完成进入增量、编译与发布 | 最多两轮职责/实践补研，并调度未检查的合格片段；仍无任务则提交前失败，保留输入/检索诊断，禁止形成成功版本 |
| 能力增量 | 已存在任意能力就跳过整段能力归纳 | 检查任务→能力→可观察单元链，保留已有成果并进行一次有限补齐；预算用尽仍有缺口则显式记录 |
| 最终合并 | 全图截到 80 节点/180 关系，后追加能力与已通过知识被静默丢弃 | 保留各有界分支的成果，不再按到达顺序截断；大图回归核对能力链与关系端点 |
| 研究历史 | 同一报告在增量加载时重复累加查询/使用量；完整重建丢失旧来源查询索引 | 按实际检索执行幂等合并；完整重建保留历史，无新增查询不重用上一轮，真实新请求照常计数 |
| 风险修复、自动发现 | 空图复用来源只走已有任务增量；新增资料压制联网；只有一部分能力时不发现其他任务缺口 | 空图恢复走完整生成；材料与检索并用；任务能力/单元缺口进入发现、计划和重算 |
| 定向研究 | 目标之外的新增内容可被整图重建带入 | 按目标关联范围和新增证据关系验证候选；整体拒绝越界提案，不通过裁剪掩盖问题 |
| 接入真实工作区 | 没有抽取到工作观察也显示完成；学习路径上下文未贯通 | 无观察保留需补材料状态；沿用范围一致的学习路径输入 |
| 聊天与登录 | 发送前清空输入，401/登录页返回丢草稿；全站会话脚本强制跳转 | 完成回答后才清空；按用户/项目/对话/快照隔离保存草稿，页面接管登录过期并保留现场 |
| 项目与对话切换 | 旧异步响应覆盖新项目；拿旧对话快照向新对话发增量 | 请求取消和身份校验，加载与显示同步；running 增量只观察已有任务，queued 增量只在基线一致时启动 |
| 自动子迭代收尾 | 图构造失败、流结束但无可核验结果时，异常在失败收尾之外 | 统一进入失败收尾；若保存失败状态也失败，同时保留两次异常供诊断 |
| 来源展示 | 进入研究清单被误读为已采纳到图谱 | 区分实际证据绑定、待核对与排除来源，显示资格理由 |
| 版本/发布 | 文件完整即可 ready，根节点空包可进入发布；私有保存与公开发布按钮含义混淆 | 结构/证据质量与文件完整性分别校验，准备、发布、恢复旧制品均检查；私有保存与公开发布明确区分 |
| 公开证据策略 | 隐藏 segment.text 后，其他对象的 evidenceSpan.quote 仍可能携带私有原文 | 公开制品同步处理原文引用与私有来源对象，源项目快照保持不变 |

## 验证与边界

- 最终集成验证：Role Atlas 351 项回归、TypeScript 检查、生产构建通过；LearnFlow 前端生产构建通过；`git diff --check` 通过。
- `cold-start-research-recovery.test.ts` 使用合成资料、受控搜索和模型响应验证有材料仍检索、英文资格、任务失败恢复、预算停止、能力补齐与来源保留。
- 既有知识/技能两维覆盖、证据逐字引用、原始快照不变、最优迭代成果保留等测试继续执行。
- 页面验证覆盖登录失效、刷新恢复、同名项目/内置示例切换、完成后清空输入及后台增量基线。
- 测试项目历史通过只读查询分析；修复不会重写既有图谱、原件、运行记录或发布记录。旧的稀疏图谱需重新执行迭代才能产生新候选。
- 已确认一条历史子记录仍为 running，但父任务因对话基线变化停止、模型调用已结束。该旧记录不等于仍在研究，亦不能据此断言是“无结果”异常造成；不批量修改历史状态。
- 合成回归证明执行契约，不能证明所有模型输出在每个专业领域都权威。正式发布仍需通过结构和证据校验，保留不确定项。

## 兼容性

冷启动 workflow 从 4.3 升至 4.4，仍读取 3.3–4.3 历史结果。复用已有研究事件、不可变版本、用户权限和学习路径契约。没有增加第四类主 Agent，也不改五核、EvidenceEvent 或掌握证据语义。能力培养规格和模型生成图谱仍是候选教学/岗位资料，不是学习者掌握证据。
