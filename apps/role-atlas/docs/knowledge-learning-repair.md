# 知识技能覆盖与学习路径修复

2026-09-07。软件实施工程师的真实执行记录中，语义补全形成 13 个知识技能，后续深研重新提取成 1 个；任务无技能覆盖从 2 增至 4，仍因来源与其他结构增益通过验收。本修复针对该退化与挂载入口断点。

## 生成与迭代

### 2026-09-08 冷启动知识生成 v4.3

- 知识 Lane 以全量任务为输入，包含默认雷达折叠的细节任务。雷达呈现及代表任务事理展开仍保持原有范围，首次岗位内核继续快速返回。
- 每组最多 2 个任务、常规组并发 2；每组证据正文预算 4,800 估算 token，单任务输出最多 3,600、双任务最多 5,600 token。每组至多一次质量补齐；传输/结构失败仍复用一次二分局部恢复。定点联网补研仍限制 3 个查询和最多 6 份来源。
- 先为每个任务保留本任务原文，再保留相关一手技术文档，余量按相关性和来源多样性分配。长段落按任务取连续原文窗口，保留原 segment ID；不修改资料存档，不拼接窗口伪造引用，也不把营销隔离来源放回模型上下文。
- 质量检查分别计算每个任务的 `knowledgeCount`、`skillCount` 与 `missingKinds`。只有一个维度也触发一次补齐；补齐保留首轮通过项。两类点齐备只是覆盖检查通过，不代表内容权威、所有主题完整或学习者已掌握。缺少资料／不适用的理由保留为待核对项。
- 提示按任务逐项检查概念、规则、操作、诊断、验收；区分岗位需要与技术文档细节，压缩重复说明，要求真实引用、适用范围和可检查评价条件。没有提取为 mention 的技术内容仍可根据原文生成。
- `build.lane.completed` 的知识质量事件增量记录 `coverage`、`incompleteTaskIds` 与 `gaps`，便于测试历史分析；`uncoveredTaskIds` 专指完全无点的任务。原有事件协议、存储和导出不变。
- 恢复已有语义版本保留知识／技能类型、评价定义和绑定的原文，避免重新编译时变回混合领域并改变 ID。现有迭代防丢与回归拒绝规则继续生效。
- 事件、编译结果与工作项缓存共用版本常量；知识调用缓存包含完整提示，旧提取结果不会因正文相同而复用。旧 v4.2 及更早快照继续可读，不自动重写或补齐线上历史项目。

验证用例见 `knowledge-context.test.ts`、`cold-start-knowledge-coverage.test.ts`、`knowledge-quality.test.ts`。运维与软件实施的流程用例使用合成来源和脚本模型，验证调度、双维度补齐、折叠任务、证据和恢复身份；它们不代替真实模型质量评估。

本次隔离副本验证：Role Atlas 全部 280 项测试、`npm run typecheck`、`npm run build` 与 `git diff --check` 通过。未调用生产模型或重新生成线上项目。Contract impact：仅升级既有岗位包生成内部流程与可选质量事件载荷；包协议、任务／知识节点关系、LearnFlow 挂载网关和五核证据语义不变，无数据库迁移。

### 既有防退化规则

- 新的 detail 知识 Lane 按任务提取原子知识／技能，必须有适用边界、评价规格、真实任务 ID，以及可核对的原文引用或有效 mention。综合能力、混合领域及无依据的点不进入原子层。
- 每组最多追加一轮定点补齐，保留首轮合格项。仍无资料支持的任务保留明确缺口，不用职业词表或数量配额填充。
- 重建只合入增量，保留基线的语义对象、关系及完整证据链。相同 ID 的既有事实优先；删除、替换与合并不由重新提取隐式完成。既有确定性安全补丁仍可按显式迁移表去重。
- 同一份资料重排时复用内容身份及片段／证据引用，避免把重新读取算作新来源。
- 验收保护已有任务、知识技能及任务到知识技能的关系。无有效迁移的丢失、类型改变或任务覆盖退步不能被其他维度的收益抵消。
- 被拒绝／无变化的候选不成为自动后续的基线，不会通过 `result.candidate` 间接替换当前快照。
- 有任务知识缺口的包不能通过语义发布门。界面分别显示运行结束、待研究缺口和正式挂载状态。

## 学习路径

Role Atlas 的 v1 映射是静态官方图的匹配建议，不是 LearnFlow 账号源图的提交回执。冷启动、迭代均传入图；展示匹配建议、待消歧、缺口和待新增候选。

进入 LearnFlow 时固定当前对话的项目版本及岗位包四元身份；需要先将该版本编译为可读取的私有岗位包。LearnFlow 复用现有 v2 解析、预览、显式应用链路，服务端仍验证主体、包版本、源图版本与幂等标识。导航不会自动创建节点，候选与正式入库状态不可混称。

## 兼容性与边界

Contract impact：修复既有 Role Atlas 构建、迭代与岗位挂载 UI；不增加主 Agent、工具、五核写入或数据库迁移。LearnFlow 源图提交继续复用已登记的零 target 审计，不表示掌握，也不创建个人学习计划。

新编译的明确原子点 ID 在原 type/label hash 后增加 `:knowledge` 或 `:skill`，同名不同类型不合并，也不与旧 hybrid 冲突。已保存的历史快照与引用不改写，旧节点在迭代中保留，去重须有明确引用迁移。
