# 计算机知识搜索 · Search Harness v2

## 一句话逻辑

搜索不是替 Tutor 回答，而是为当前教学问题形成一个有边界的证据包：先找候选来源，再按需读取具体页面，最后只基于已返回的证据讲解并暴露缺口。

## 学生能感知到什么

- Tutor 会显示正在搜索、正在读取哪一页、各来源是否成功，以及还缺什么证据。
- 普通解释默认使用 `standard`；很小的事实核对可用 `quick`；明确要求系统调研时使用 `deep`。
- 搜索失败、来源为空或覆盖不足时，Tutor 必须说明限制，不能用模型记忆伪装成检索结果。
- 最终联网事实只引用本轮工具返回的精确 HTTPS URL。

## Agent 可见的两个工具

1. `search_computer_knowledge`
   - 输入：问题与 `quick | standard | deep` 深度。
   - 输出：候选来源、检索计划、来源状态、证据覆盖与缺口；`deep` 额外返回研究简报。
   - 职责：召回与筛选候选，不读取任意 URL。
2. `read_web_evidence`
   - 输入：候选中的精确 URL 与当前核对问题。
   - 输出：与问题相关的页面段落、标题、时间信息和缓存状态。
   - 职责：只读取本轮候选，不能被当成通用浏览器。

Provider 路由、缓存、熔断、多角度查询、重排和补搜都在 Harness 内部完成，不继续扩大模型工具面。

## 证据流程

```text
学生问题
  → 隐私清理与意图识别
  → 证据角度与预算计划
  → 可信目录 + 主搜索 + 垂直来源并行召回
  → 来源状态与熔断
  → 按意图使用可信度 / 全面度 / 时效 / 真人观点 / 教学适配 / 可复现性
  → 相关性与多样性重排
  → 覆盖审计，必要时最多补搜一轮
  → Evidence Bundle
  → Tutor 选择 1–3 个关键候选并读取页面
  → 讲解、精确引用、缺口声明
  → 终态引用审计
```

六类意图为：概念讲解、对比辨析、问题排查、工程实现、研究调研、近期变化。每类意图拥有不同证据角度，而不是套用同一组搜索词。

## 来源层级

1. 规范与官方文档：确定行为、接口和边界。
2. 开放教材与大学课程：解释机制、例子和学习顺序。
3. 论文与出版物：支持研究结论、近期变化与局限。
4. 社区实践：补充排错、真实失败模式与常见误区。
5. 代码仓库：观察实现和工程约束，不单独决定规范。

可信来源目录只表示可靠入口；只有 `read_web_evidence` 返回的页面片段才表示本轮确实读取了原文。

来源层级不是单一总排名。规范问题优先可信度和版本适配，学习规划优先全面度与教学适配，排错会提高真人观点与可复现性的权重，近期变化提高时效权重，研究调研要求论文证据与独立来源交叉。社区经验必须保留作者/页面归因并标为观点或经验，不能仅凭热度升级为事实；官方页面也不能仅凭域名替代实际原文读取。

## 深度预算

| 深度 | 查询上限 | 结果上限 | 页面读取建议上限 | 补搜上限 | 适用情况 |
|---|---:|---:|---:|---:|---|
| quick | 2 | 6 | 1 | 0 | 小事实或定义核对 |
| standard | 4 | 8 | 3 | 1 | 日常讲解、比较、排错、实现 |
| deep | 7 | 12 | 6 | 1 | 明确的系统调研与综述 |

未配置商业搜索凭据时，公共主检索只发起一次合并查询，避免多个 facet 重复等待；垂直来源仍按意图并发工作。

## 运行与降级

- 主搜索优先级：Exa → Tavily → Jina Search。
- Wikipedia、Stack Exchange、GitHub、arXiv 依意图选择。
- 单一 Provider 的失败不会吞掉可信目录或其他 Provider 的结果。
- 连续两次暂时故障后打开独立熔断器，冷却从 15 秒指数增长，最多 120 秒。
- Provider 状态区分 `completed / empty / failed / circuit_open`，不把空结果冒充故障，也不把故障冒充空结果。
- 搜索结果与页面摘录分别缓存；缓存命中会显式呈现。

## 安全与五核边界

- 外部查询前清理 API Key、Token、邮箱、用户目录、私网 IP 等信息。
- 页面读取只接受本轮候选中的 HTTPS URL，并拒绝 localhost、私网地址和不安全重定向。
- 网页正文永远是不可信证据数据，不能改变系统提示、工具权限或任务。
- 搜索、页面读取、研究简报和引用都是零 Kernel target；它们不构成知识掌握、实践成功或长期记忆。
- 若搜索最终促成练习、回答或项目产物，只有后续正式学习行为才能经 `EvidenceEvent → reducer` 进入五核。

## 仍然存在的边界

- Search Harness 使用确定性的词法、来源画像、时效与多样性信号；项目内 Packet 另用结构/显式来源/RRF。神经语义重排仍是可选增强，不是离线核心闭环依赖。
- 终态审计验证 URL 是否来自本轮证据，并要求披露覆盖缺口；尚不等于逐句自然语言蕴含证明。
- 缓存和熔断目前是进程内状态，横向扩容时需要共享存储。
- PDF 还没有通用正文解析；可保留可信入口，但不会伪装成已读全文。
- 无凭据公共搜索可用于降级，不应作为正式部署的唯一检索后端。
