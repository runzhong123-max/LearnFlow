# LearnFlow 逻辑书 · v0.13

> 一分钟版本：这是当前产品的全部逻辑。想改产品，先改这页。

## 产品

LearnFlow 是一个持续陪伴学生学习的对话空间。

当前保留五个页面：

1. **Chat**：学生和 Tutor 持续讨论学习问题。
2. **学习任务**：查看由对话或项目形成的正式原子任务队列，并暂停、恢复或结束任务。
3. **学习路径**：在知识星云中按数学、专业基础、AI、安全、硬件、系统等星团查看课程关系，标记自报状态、管理个人节点。
4. **我的画像**：按核检查正式 KernelState、Module 与 Claim，并进行归档、恢复、确认、纠正或撤回。
5. **设置**：配置模型连接与最基本的产品偏好。

## 对象

| 对象 | 只负责什么 |
|---|---|
| Conversation | 保存一段独立、可继续、可确认删除的对话 |
| Page Tab | 让多个对话和设置页同时打开、切换、关闭；其中一个可作为并排副页 |
| Settings | 浏览器保存模型地址和名称；本地服务只从 `frontend/.env.local` 读取 API Key |
| Tutor State | 只决定当前或下一轮对话怎样回应 |
| Agent Turn | 服务端唯一的有界观察—工具—再观察循环；保存 ContextEnvelope、工具轨迹、预算和终态校验结果 |
| Agent Session | 正式对话连续性和作用域；带领学习时拥有当前 SkillRun |
| Tutor Substate | 展示正式 SkillRun 正在怎样带领学习；浏览器只镜像当前步骤，不另存第二套状态 |
| Tool Run | 保存一次搜索、图解或动画调用的状态、耗时、来源与产物；不判断掌握 |
| Follow-up Sheet | 保存一段选中文字和围绕它展开的分支对话；继承父页上下文，不复制用户画像 |
| Learning Task | 正式任务队列里的一个原子学习目标、来源、暂停点与生命周期；不规定通用教学流程，不代表掌握 |
| Learning Skill / SkillRun | Skill 定义方法；正式 SkillRun 保存当前步骤、循环、版本和验证入口，并绑定同目标 LearningTask |
| Planning Dialogue | 对话内较大目标的信息收集过程；分为项目雏形与发展方向，不是长期计划权威 |
| Learning Path Plan | 学生确认后的长期课程路线；与 Planning Dialogue 分离并保留版本 |
| Value Claim Proposal | Tutor 根据学生明确表达提出的价值核修改候选；学生可接受、修改或拒绝，只有明确接受才通过正式事件网关写入 Value |
| KernelState / Module / Claim | 可追溯、可检查、可纠正的正式五核状态与长期记忆；Agent 只读取有预算的 ContextPacket |
| Official Path Node | 版本化课程 DAG 中的共同坐标；来自公开培养方案，不是强制学习顺序 |
| Personal Path Node | 学生确认加入的个性化课程或技能节点；可删除，并以有向边连接已有图 |
| Path Event | 自报状态、个人节点添加或删除的正式 EvidenceEvent；更新 Structure，必要时只在 Knowledge 留下“自报接触”，不写掌握 |
| Graph Alignment | 显式连接课程路径（含个人覆盖）、个人概念、来源知识领域与长期路线；只对齐身份和关系，永不携带掌握结论 |

## 四种状态

| 状态 | 行为 |
|---|---|
| 自由态 | 默认状态；自然讨论、回答、澄清，不擅自创建学习任务 |
| 简单讲解态 | 先给必要解释，再按需给核心机制、最小例子和一个自检问题；一轮后回到自由态 |
| 带领学习态 | 围绕同一原子目标，在当前对话中组合 Skill、练习和检查；暂停或结束后回到自由态 |
| 学习规划态 | 处理跨多个任务、较复杂产物或未来方向；形成项目启动雏形或发展建议，不自动创建项目或改写五核 |

学生可以手动指定下一轮。自由态识别到“什么是 / 讲讲 / 解释”等明确请求时，也会自动将该轮交给简单讲解态。简单讲解不能只用追问代替开场解释。

当前四个 Learning Skill 都只绑定**带领学习态**。学生可在输入栏直接选择 Skill；尚无任务时，选择会把下一轮绑定为带领学习态，发送消息后才建立正式 Session、SkillRun 和同目标 LearningTask；任务运行中切换方法会启动新的正式 SkillRun。Skill 的每一步同时声明一个子状态，例如“带领学习态 · 引导态 / 示范态 / 复述态 / 迁移态”。子状态由正式 SkillRun 确定性推进，浏览器事件只做显示缓存或明确标注的离线回退，页面和模型都不能自行跳转。

明确的“带我学 / 带我弄懂 / 带我练”会建立正式原子任务。清晰讲解、苏格拉底追问、费曼复述、示例渐隐各自拥有不同的步骤与循环。要求学生产出的步骤必须收到真实回应；“不知道 / 要提示 / 换一种支架”只增加支援轮并留在本步。正式运行时页面不提供可绕过回答门槛的“下一步”。任务流程完成仍不是掌握；掌握只允许由 Practice 的判题、独立尝试和迁移证据形成。

“系统学习 / 学习路线 / 几个月完成 / 做一个真实项目”和职业、科研、发展方向问题会进入学习规划态。项目雏形依次收集目标产物、当前基础、来源资源、时间投入、实践验收和现实约束；当前只形成可检查草案，“项目尚未接入”必须始终可见。发展规划先比较方向与低成本探索证据；只有学生明确表达长期倾向时才出现 Value Claim Proposal，并同时展示当前内容、建议内容、原话依据和影响范围。接受前不写 Value；接受后由正式网关记录带作用域的确认事件，再由 reducer 归约，UI 和 Tutor 都不能直接改 KernelState。

学习规划态优先读取“官方课程 DAG + 当前学习者个人覆盖层”。已知主题只把匹配节点和前后关系作为柔性锚点；不能可靠匹配的主题先联网确认与已有课程的关系，再生成个人节点提案，只有学生点击确认才加入。硬前置、软前置、建议共学都保持有向无环；“自报掌握”只用于结构导航，不升级 Knowledge 核掌握。

## 当前流程

```text
打开 LearnFlow
→ 新建或继续一个对话
→ 默认进入自由态
→ 普通消息由自由态回应
→ 解释请求进入一轮简单讲解，再回到自由态
→ 原子学习请求在当前对话进入带领学习态，并显示轻量任务控制条
→ 建立或恢复正式 Agent Session，启动 SkillRun 并绑定同目标 Learning Task
→ 正式 Learning Task 进入全局任务队列，可从原对话恢复
→ 也可以先在输入栏选择学习方法，再用下一条消息建立该 Skill 的任务
→ 当前 SkillRun 步骤投影为“带领学习态 · 子状态”，按确定性 learner-reply gate 转换
→ 较大目标或发展方向进入学习规划态，在对话中形成规划草案
→ 规划态读取学习路径图；图谱缺口先搜索，再展示可确认的个人节点提案
→ Value Claim 修改必须由学生查看依据后接受、修改或拒绝
→ 可以同时打开多个对话
→ 任一其他已打开页可以与当前页并排
→ 可以打开设置而不丢失对话现场
→ 可以单独打开学习任务、学习路径和我的画像，并与对话并排
→ 每轮进入唯一 Agent Turn Graph：组装 ContextEnvelope，先做必要观察，再由模型选择已登记低风险 ACI
→ 工具结果作为结构化 ToolMessage 回灌；失败可在同一预算内重试、换工具或透明停止
→ 终态校验拦截未确认写入、无证据掌握、隐藏失败和缺少搜索引用
→ 回答先显示工具过程和来源/产物，再显示 Tutor 解释
→ 选中 Tutor 原文可新建一张追问纸，并在纸张间切换
→ 刷新后恢复已打开页面
```

删除对话必须先确认；确认后同时删除该对话及其页签。删到最后一条时自动创建一个空白对话。

模型请求固定经过本地 `/api/tutor`。API Key 不进入页面、不写 `localStorage`，修改 `.env.local` 后重启服务生效。

对话正文按 Markdown、GFM 和 LaTeX 数学公式渲染；原始 HTML 不执行。

搜索先识别讲解、对比、排错、实现、研究或最新变化，再围绕任务寻找互补证据。来源按“规范/官方文档 → 教材/大学课程 → 论文 → 社区实践 → 代码仓库”确定性重排；“什么是”默认覆盖定义、机制、最小例子和边界/误区。网页内容只作为不可信资料进入回答，搜索与讲解不写五核。完整约束见 `COMPUTER_KNOWLEDGE_SEARCH.md`。静态图只保存消毒后的 SVG；动画保存 3–9 个安全 SVG 步骤，由本地播放器切换，不运行模型生成的脚本。

五核画像现在读取正式后端的 KernelState、MemoryFact、Module 与 Claim。它是全局学习者对象，不属于某个 Session：最上方全局栏与左下角学习者卡片打开独立画像页；Reader 不把整份画像塞给模型，而是通过 ContextPolicy 按问题和作用域裁剪。结构与知识共享主题锚点但分别判断导航与理解；Human 敏感内容只转成静默适配；Value 的长期方向必须经学生确认；Practice 的能力 Claim 必须引用独立产物或迁移证据。用户“删除”当前参考内容时，系统追加归档/撤回/纠正事件并保留历史审计，不改写原事件。

若本轮相关的新自述与既有 Claim 冲突，Reader 会把冲突作为只读观察交给 Tutor；终态校验要求 Tutor 明确说明不一致并把纠正权留给学生，不能静默覆盖。项目来源进入工作区时会生成 `sourceConstraint`：路线和讲解受当前来源覆盖范围约束，超出部分必须标记为资料缺口并补充证据；来源覆盖永远不携带掌握结论。

带领学习态与规划态还会读取正式学习工作区：近期 Attempt、开放纠错、到期复习与当前项目来源领域按 learner/session/project/checkpoint 裁剪后进入同一 ToolMessage。这里只显示 outcome、辅助等级、调度和错因标签，不发送提交正文或答案；任务完成、有提示成功、独立成功和变式迁移始终是四种不同事实。

学习路径当前由 96 个官方节点、155 条有向边和正式学习者覆盖层构成，覆盖高职、本科、研究生的计算机、软件、网络、云计算、大数据、AI、安全、移动开发与现代 Agent 工程。课程路径、个人概念、项目来源知识领域和已确认路线通过显式非掌握 Alignment 连接；无法可靠匹配的对象保留为 gap。完整数据、来源、匹配与个人节点规则见 `LEARNING_PATH_GRAPH.md`。

路径页默认显示筛选范围内的全部有向边，箭头从前置指向后继；悬停星体时高亮它的一跳关系并弱化其他节点与边。节点按九个相邻主题星团凝聚定位，大小表示连接度，颜色表示主题，状态环表示正在学习或学习者自报。阶段和培养层次只做筛选，不再决定画面布局。

主对话是一张不可删除的纸。选中 Tutor 文字后创建子纸；子纸读取主对话、祖先纸和本页消息，但新消息只写本页。其他纸压在当前纸下，悬停纸边可横向展开并切换；第一次点击桌面空白会缩小平铺全部纸张，再次点击空白会按父子关系展开纸张树。任意追问纸均可单独删除，直接子纸会保留并上移一层。纸张不产生新的长期学习状态。

## 现在明确不做

- 不创建项目。
- 不判断掌握程度。
- 不让 UI、工具或模型直接写 KernelState；所有写入只走 EvidenceEvent 与确定性 reducer。
- 不把路径页的自报状态、个人节点、图上距离或任务完成直接当作 Knowledge 掌握。
- 不把未确认的 Value 候选写成长期方向；拒绝和修改也必须保留学生知情与判别权。
- 不把讲义生成、Skill 步骤、普通聊天或任务结束当作评分和独立实践证据。
- 不用占位内容假装模型已经回复。

## 后续增加功能的规则

1. 一个新对象必须能用一句话说明职责，否则不加。
2. 同一种状态只能有一个权威来源。
3. 页面只是视图，不能自己决定学习状态。
4. 先走通一个真实用户流程，再增加新的页面和 Agent。
