# Visual Storyboard v1 十案例验收

> 历史记录：本文记录 2026-08-31 的 SVG storyboard v1 验收。当前主实现已由 `ASCII_STORYBOARD_V2_EVAL.md` 取代；这里的 10/10 不能作为 ASCII v2 的模型成功率。

日期：2026-08-31

## 范围

本轮只使用 `frontend/server/visual-storyboard-cases.ts` 中固定的十个上下文，不追加临时提示，不按主题切换模板。每个上下文都包含稳定对象 ID、关系、分组、初始状态、类型化操作、逐帧断言、学习目标与事实边界。MiMo 仅承担 Skill 层的“讲解 -> 结构化上下文”编译；Tool 层始终使用同一套引用校验、状态重放、断言、布局、碰撞/越界、SVG 安全和渲染逻辑。

确定性编译为 10/10，通过 39 个作者定义步骤（产物另含初始帧）；真实 MiMo 编译最终为 10/10。所有确定性产物的当前质量分为 84：这是结构验证级上限，不把没有视觉模型评审的产物虚报为更高等级。

事件循环的早期真实调用暴露了一个通用协议歧义：`group_members` 本身有顺序，但 `order` 断言原本只读取显式 `orders`。修复为“显式顺序优先，否则读取成员顺序”后，同一固定上下文重试通过。该修复没有增加事件循环特例。

最终严格版全量运行首轮为 9/10：矩阵案例把 `misconceptions` 放在根级而非嵌套 storyboard，旧验证器直接访问缺失字段并抛出 TypeError。Skill 现在把根级同义教学字段归一到 storyboard，Tool 对缺失目录、初态、教学上下文、presentation、operations 或 assertions 返回稳定协议错误。矩阵单例用完全相同的固定上下文重跑通过，最终严格版结果为 10/10。

## 浏览器视觉复核

在 1440×1100 视口逐帧渲染十个案例，并重点检查哈夫曼树最终帧、事件循环最终帧和联邦学习最终帧。复核中发现并修复两类通用布局缺陷：

1. 密集泳道节点发生垂直重叠，而旧质量报告把碰撞数固定为 0。现在按泳道密度缩放节点，并从真实边界框计算碰撞与越界；任一命中都会阻断产物。
2. 不同泳道间的关系线可能交叉。现在图层布局和未分组泳道使用基于邻接关系的重心排序，同时保留显式业务顺序。

最终重点帧无节点重叠、无越界，事件循环的两条异步关系线不再交叉。浏览器控制台唯一错误是静态验收页缺少 favicon，与动画产物无关。

## 失败语义与密钥

讲解由 Harness 先提交，视觉 Skill 或 Tool 失败只进入 `explanation_only`，不得撤销讲解。测试从现有 `backend/.env` 读取 MiMo base URL、model 与 API key；评测输出、文档和提交均不包含密钥值。
