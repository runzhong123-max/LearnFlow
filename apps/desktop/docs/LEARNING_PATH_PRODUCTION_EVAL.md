## 从评测中发现并修复的问题

1. `系统部署与运维` 曾被意图抽取器错误去掉“系统”；改为只有“系统学习”完整短语才是意图包装。
2. `统计学习理论` 曾被内部“学习”二字截断；意图抽取改为仅匹配句首学习动作，精确读取先尝试原文。
3. `研究课题与学位论文` 曾被句首“研究”误判为动作；原始标题 exact 优先后恢复。
4. `軟體工程` 与 `數據庫原里` 曾无法稳定解析；检索 v3 增加课程术语和有限错字归一化。
5. 旧路线最终按手工 `order` 排序；改为硬/软前置拓扑排序，`co_learning` 不再制造先后关系。
6. 旧层次筛选会隐藏硬前置；现在递归补入并在星图上标为“补充前置”。

## 安全与证据边界

- 路径读取和路线提案是 Structure / Value 参考，不产生 Knowledge mastery。
- 搜索结果和个人节点提案均为零 Kernel target。
- 个人节点正式写入仍需学习者确认，并沿既有 EvidenceEvent 链归约。
- 模型不能通过工具参数伪造来源 URL，也不能用搜索相似度决定硬前置。

## 仍需持续评测

- 当前 61 个旧课程节点仍使用短通用摘要；它不阻塞检索和依赖正确性，但不足以直接生成高质量课程
  教学规格，应分领域补充知识范围、学习成果、实践产物和证据要求。
- 真实联网来源质量会随搜索供应商变化；上线观测应记录证据拒绝率、消歧率、错误个人节点提案率和
  学习者修改率，不应只统计工具调用成功率。
- 学历标签表示适用课程集，不代表每位学生都必须学习；最终路线仍需结合五核、目标和已有证据。
