# 五核即时教学指导

Contract impact：registry `2026-09-05.3`，新增 `teaching-guidance.v1` 控制投影。保留五核与三类主 Agent，没有数据库结构迁移。

## 两条独立生效路径

原有 Module/Claim 门槛用于长期证据结论，不再决定下一步是否调整教学。

```text
用户原文／明确界面选择／正式评分事件
  → EvidenceEvent → 确定性 reducer → KernelMutation → KernelState
  ├─ 当前教学指导 → 有范围的 ContextPacket → 下一次 Tutor／规划决策
  └─ 可合成学习事实 → 原有 Module／Claim 合成与能力证据门
```

即时指导存放于各核 `short_term.teaching_directives`；明确持续教学偏好存放于
Human 的 `long_term.teaching_preferences`。两者是事件与 mutation 支持的控制投影，
不再送进通用 Fact/Module/Claim 重复总结，避免把临时指令永久化、重复计证据或复活旧指令。
它们不成为第二套画像权威，也不改变 Knowledge/Practice 的评分、通过与掌握规则。

## 生命周期与优先级

| 类型 | 例子 | 生效与结束 |
| --- | --- | --- |
| 当轮 | 这次回答简短；卡点已解决后的衔接检查 | 同一会话下一条用户输入替代；读操作不消费，重试可重放 |
| 会话／具体题目 | 今天只有十分钟；这一步没懂；本题刚答错 | 立即指导本情境，最长八小时；后续明确更新或同题新表现替代 |
| 明确持续偏好 | 以后代码示例优先用 Python | 单次明确请求即生效，不等三个证据；可更新、取消或停止使用 |
| 模型候选 | 尚未确认的学习线索 | 只支持当轮一个必要的澄清问题，不作为已确认能力或背景 |

每条指导携带核、slot、来源事件、发生时间、到期时间、作用范围、证据种类、版本与确定性优先级。
同情境新指令替代旧指令，临时要求优先于持续默认。答错只指导当前题目的反馈与重试，不能顺带推断
挫败、人格或长期基础；辅助成功不能按独立成功指导。学生说懂了只能解除自述卡点并进入小检查，
不能升级稳定掌握。

Structure 指导返回或补充哪个学习位置；Knowledge 指导如何澄清当前卡点和校准自述起点；Human
指导本次节奏、时间和呈现；Value 指导当下优先推进什么；Practice 指导如何处理这次实际尝试。

## 实际接入

- 网页在 Tutor 请求前同步 `vnext_teaching_input_received`，只传原始用户文字。插件引用、隐藏控制消息
  和助手内容不作为本人教学要求。稳定消息 ID 保证重试幂等；同 ID 改文字或范围返回 409。
- API 校验正式会话及项目／检查点归属，原文最多 20,000 字，忽略客户端自定指导字段。
- Native Tutor 复用已有 `user_message` 事件；带领学习的技能回合若已入账，网页跳过重复输入，Native 渲染复用该事件。
  两种 API 均支持 `direct_user_text`：缺省兼容旧客户端，明确空串表示隐藏控制或纯资料，不能回退到拼接消息。
  新客户端统一使用稳定消息 ID；技能回合同步失败先停止回答，重试复用原会话和回合，避免跨入口重复写入。
- ContextPacket 从五核状态确定性选择指导，先过滤范围、到期与归档，再按优先级控制数量和 token 预算。
  缺失会话不能读取其他会话的临时指导。无范围的旧兼容投影不附带这些控制字段。
- 网页与 Native 的每次模型调用均附加动态用户上下文，包括简单解释和视觉生成分支；不等待模型选择记忆工具。
  深度记忆检索仍按需调用。学习任务规划直接读取同范围指导。
- 画像记忆管理可查看并停止使用这两类控制投影；停止使用还会影响 ContextPacket 选择。

## 兼容性与验收边界

旧事件和长期知识保留，不重新解释全部历史聊天，不批量改写真实学生状态。旧客户端可忽略新增字段；
只更新后端而不更新前端时，网页普通消息仍可能没有即时输入事件，因此应一起发布。
部署回退应同时回退写入和消费代码；保留新事件供后续重放。

规则提取仅扫描前 4,000 字内的明确常见表达，是确定性实现，不宣称通用自然语言理解。未匹配文字仍由 Tutor 原对话处理，
但不冒称已经更新五核。八小时是本轮工程上限，尚非个体化遗忘模型；题目指导限具体题目／检查点，
不等于整个长期项目一直受该次表现约束。真实教学效果仍需学生试点。

验收覆盖一次输入立即读到、无 Claim 仍生效、同输入幂等、异文冲突、跨用户／会话隔离、当轮失效、
时间到期、偏好覆盖与取消、否定与转述、评分等级、无工具首个模型调用已含指导，以及原有架构回归。
