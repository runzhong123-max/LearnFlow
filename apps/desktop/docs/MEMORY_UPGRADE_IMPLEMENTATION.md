# 五核记忆升级实施记录

本轮实现依据用户批准的《LearnFlow 五核记忆系统升级计划书》。本文件区分工程验收和真实学习收益，不把自动化测试当作学生试点。

## 合同与兼容性

Contract impact：registry `2026-09-05.2`；Module policy `memory-module-version-v2`；复习熟练度采用 v2 证据门。没有数据库破坏性迁移或第六核。

- `semantic_observation_proposed` 保存模型候选、原事件引用与策略版本；候选不能覆盖用户自述或升级掌握，禁止参与长期合成。
- Profile PATCH 按字段合并。目标对象与操作幂等身份分开；A→B→A、确认→探索均同步归约。
- 反馈事件携带 `affected_keys/affected_fact_ids`，先令旧认识失效并清除适用typed投影；合成不能让撤回内容复活。反馈API返回有效状态与独立合成状态，旧客户端不依赖queued才能刷新。
- 合成按独立事件计门槛，优先处理新验证/纠正；同证据可重试最多3次。Knowledge/Practice草稿使用record/independent_success/stable_mastery/transfer类型，能力措辞由证据门控制。
- 检索先scope再候选窗口，精确主题、查询和热引用分路召回。所有路径统一过滤，SUPERSEDES作为resolved_updates而非待确认冲突。归档字段的图谱衍生认识也停止采用。
- Tutor新查询真实检索并复用同轮缓存；保留时间、来源、范围、缺失状态。所有聊天模式均可读取工作区。
- 创建/重规划使用相关有scope的ContextPacket；出题传learner身份；重做失败仅局部策略轮换，显式拒绝也限定情境；无变式不显示可迁移。
- 画像首页四块：当前重点、已有基础、最近进展、如何帮助我；来源和缺失时间明确，原技术明细折叠保留。

## 验收与剩余边界

新回归覆盖否定/转述/测试场景、跨学科原话、修改生命周期、撤回、合成阻塞、关联过滤、长期旧项目召回、来源身份、教学scope、能力标签以及画像展示。

本轮前端提取仍是保守规则，混合引文/主体会漏提取；不宣称通用语义理解。自述录入入口仍保留现有明确表单与规划流，不把所有聊天自动变成长期认识。历史错误归属不能凭模型猜测重写。本轮未迁移真实学生数据库。

真实学生试点、7/30天学习收益、个人遗忘校准均待真实观察。按 `MEMORY_PILOT_PROTOCOL.md` 收集对照证据；离线脚本仅评测检索/状态合同。

### 本轮实测

- 后端全量回归通过，包含架构漂移、作用域隔离、纠正与撤回；最终结果以发布验收日志为准。
- 前端全套 365 项测试与生产构建通过；浏览器在独立临时数据库登录、展示四块画像、修改偏好并即时更新，停止使用后可见停用状态与恢复入口。
- 浏览器发现并修复旧页面把 growth area ID 当 kernel ID 使用的问题，避免有记忆却显示 0 条且不能停止使用。
- 三组检索各执行 3 次：近期窗口遗漏旧锚点，精简事实和五核命中；三组均未引用已失效目标。未覆盖主题时，五核仍返回 9 条项目背景，这是实际限制。
- 合成小样本本机中位检索时延：近期窗口/精简事实约 1.6–1.8ms，五核约 16–17ms；五核约 2,741–2,758 估算 token。仅表示该夹具上的工程成本，不能外推线上时延或学习收益。
- 未执行真实学生试点、生产部署和真实历史数据迁移；比赛 demo 启动未执行，本轮不修改 demo 流程。
