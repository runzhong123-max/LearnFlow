# 桌面云端账号与设备连接 v1

用户在 2026-09-06 要求桌面默认使用网页同一账号。本契约替代此前“主窗口默认本地账号、在线窗口另行登录”的首发安排。

- 主窗口使用随安装包构建的本地 UI，通过带每次启动随机 token 的 loopback sidecar 访问固定 HTTPS LearnFlow 云端。云 Cookie 与 CSRF token 只在 sidecar 内存中，Webview 仅持有随机本机会话句柄；密码不落盘。重启应用后重新登录。
- 云端负责注册、邀请码、密码、会话、项目、Tutor、学习任务、复习、五核和岗位网关。连接失败明确报错，不自动切回本地身份；写请求不自动重试。登出丢弃本地句柄，账号切换使旧句柄失效；云端撤销与过期继续由现有认证服务验证。
- 旧本地账号与数据库保留。登录页可明确进入旧工作区；不按用户名自动合并身份，不导入旧学习记录。缓存按云端源站、学习者 ID 隔离，避免与本地同号学习者混用。
- 云项目可以绑定本机目录。每次文件/实验操作先通过云端 auth/me 与项目 ownership 检查，绑定按 origin + learner_id + project_id 存在本机 runtime/cloud-devices；云端不可指定本机路径。文件内容默认不上传，用户“请导师解释”等显式行为才发送选择的内容。
- 文件读写复用路径与保护规则，写入验证基线 hash，保留本地历史，重复请求幂等。实验复用 C11 固定参数执行器：先预览固定快照，再确认 hash 与可信本机执行，验证过期及源文件/快照漂移。运行结果只是本机操作记录，不调用 record_event、不决定五核或通过状态。其 journal 不是 EvidenceEvent；若未来将结果作为正式提交，必须通过云端统一事件入口。
- 桌宠只接收 10 分钟受限句柄，可读取会话、云复习概览并向所选云会话提问，不能读取账号凭据、访问设备目录或执行任意云接口。系统选中文字只在用户发送后随问题提交。图片、文档观察等旧桌宠能力保留于旧本地模式，云模式不冒充已接通。
- 云项目中的本地文件与实验界面复用既有工作台；旧本地实践案例/阶段交付保持原模式。完整离线事件重放、自动文件同步、旧数据库导入与跨设备复制实验历史不属于本契约。

Contract impact：桌面 registry 2026-09-06.8-desktop，新增本机连接适配合同并扩展既有文件/实验绑定。三类主 Agent、评分策略、EvidenceEvent 与云端 API 均未改变；无数据库迁移，Web 后端无需更新即可认证该客户端。
