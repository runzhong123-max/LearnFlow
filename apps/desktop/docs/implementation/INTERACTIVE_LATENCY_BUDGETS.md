# 交互式时间预算

LearnFlow 将用户可见的等待预算按所有权分层，避免外层先于内层工作结束。前端单一事实源是
`frontend/src/latency-budgets.ts`；后端可部署预算由 `backend/app/core/config.py` 提供。

## 前端预算矩阵

| 路径 | 外层 Tutor | Agent 回合 | 子调用 |
| --- | ---: | ---: | ---: |
| 普通/简单讲解 | 420 秒 | 360 秒 | 单次模型 180 秒 |
| 学习规划 | 540 秒 | 480 秒 | 单次模型 180 秒 |
| 带领学习 | 600 秒 | 540 秒 | 单次模型 180 秒 |
| 图解 | 660 秒 | 600 秒 | 规划 150 秒，修复 120 秒 |
| 动画 | 780 秒 | 720 秒 | 规划 210 秒，修复 150 秒 |

正式后端 API 为 120 秒，后端代理为 180 秒，搜索 provider 为 20 秒，视频 provider 为 30 秒，
桌面 sidecar 启动为 180 秒。每层仍有硬截止时间，超时后必须透明返回失败，不得冒充产物。

## 后端默认预算

- Tutor 单次模型工作：180 秒。
- 学习任务规划：120 秒。
- 微学习产物生成：180 秒。
- 常见视觉、讲义、练习与概念生成：120–300 秒。
- 远程来源总预算：默认 90 秒，上限 180 秒；Git 拉取 180 秒。

## 不随交互预算放大的保护边界

密码哈希队列、数据库锁等待、学习代码执行、受信本机 Agent 的任务上限、进程终止 grace period
和健康探针仍使用各自的资源保护超时。这些超时限制阻塞、资源占用或执行风险，不属于模型生成等待。

修改预算时必须维持 `外层 Tutor > Agent 回合 > 单次 provider`，并更新预算单测、架构版本和本文。
