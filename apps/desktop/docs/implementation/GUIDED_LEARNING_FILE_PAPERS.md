# 文件驱动带领学习与纸张工作空间

## 目标

让 Tutor 像正常 Chatbot 一样保持连续对话，同时把长讲义、练习题和来源正文留在可操作的纸张里。对话负责提出一个当前锚点和下一步，文件负责承载内容，正式 Attempt 负责产生证据。

## 对象与权威

| 对象 | 权威 | 用途 | 是否是掌握证据 |
| --- | --- | --- | --- |
| 主对话 | `AgentSession / AgentMessage` | 连续 Tutor 对话 | 否 |
| 讲义 | `Lecture` 当前版本 | 阅读、引用、自检 | 阅读本身否 |
| 练习 | `ConceptQuestion / Exercise` | 正式作答入口 | 仅提交后的 Attempt |
| 来源 | `Source / Chunk` | 有 provenance 的不可信上下文 | 否 |
| 纸张 | 浏览器 `PaperSheet` | artifact ref、父子关系、分支消息 | 否 |
| 五核 | EvidenceEvent reducer | 学习者状态 | 只接受已登记证据 |

纸张不复制文件正文。`PaperArtifact` 只保存 `kind`、稳定对象 ID、标题和必要的会话引用；正文打开时按 learner scope 从后端读取。

## 纸张树

每个 Chat 有一张不可删除的主纸。讲义、练习、来源和选中追问都可以成为任意纸张的子纸：

```text
主对话某条回答
  ├─ 讲义纸
  │   ├─ 来源纸
  │   └─ 对讲义段落的追问纸
  └─ 练习纸
      └─ 错题解释追问纸
```

恢复时执行确定性修复：去重 ID；无效、缺失、自指父节点回挂主纸；检测到环则切断到主纸。删除中间纸时，其直接子纸重挂到被删纸的父节点，因此学习分支不会丢失。模型上下文按“主纸摘要 → 祖先纸摘要 → 当前纸”装配，并受 token budget 约束。

## `learning_file_study` Skill

Skill 属于 `pedagogical_method`，只能绑定 `guided_learning`：

1. `selecting_learning_artifact`：至多三句话直接介绍目标，然后优先复用已有受管文件；没有文件时只显示一次讲义+练习生成确认卡。
2. `reading_with_anchor`：读取当前文件，每轮只给一个阅读锚点、例子或检查问题；可以在本状态循环。
3. `practicing_in_file`：把作答留在练习纸；Tutor 不读取答案，Practice Agent 负责提交和反馈。
4. `verification_ready`：进入无提示、可判定的独立验证；只有正式 Attempt 可以改变证据状态。

用户可以随时自由追问。追问不自动推进 Skill；“不知道”“换个例子”会留在当前状态并降低支架，而不是假装完成。

初始导入不是一份缩小版讲义。它只负责让学习者知道“正在学什么、为什么有用”，随后把定义展开、例子、边界和正式题目交给文件纸张。默认不搜索网页或视频，也不要求学习者先在视频、文档和测试之间做资源选择；只有学习者明确提出外部资源需求时，资源策展 ACI 才进入本轮工具面。

## 工具政策

`read_active_learning_file` 是唯一给模型的当前文件读取 ACI：

- 参数为空，防止模型枚举任意文件 ID。
- 只在 `activeArtifact` 存在时进入 allow-list。
- 讲义返回当前版本与来源；练习只返回 answer-free 题面；来源返回有界 chunk 与不可信标记。
- 同一回合最多自动读取一次；已有观察以 ToolMessage 回灌。
- 文件生成仍使用已有 Action Board 能力，先确认副作用，再持久化正式对象。
- Harness 从当前正式 LearningTask 的 `artifact_refs` 判定是否已有文件：存在时直接产生可打开的文件交接卡；不存在时复用既有生成能力产生确认卡。该分支不交给模型猜测，也不增加新的模型工具。
- 视频搜索成功但字幕/ASR 核验只有 `metadata_only` 时，只能标为待核验，不得输出“适合你”“推荐观看”等正向适配结论。

普通自由态和简单讲解态不再默认读取完整五核和学习工作区。只有带领学习、规划或用户明确问个人进度/错题/掌握度时才读取对应投影，以减少首字延迟和无关上下文。

## 前端呈现

- 嵌入纸张的文件头为轻量、半透明、渐隐题头，不显示逻辑文件名或内部 checkpoint 编号。
- 整张纸只有一个纵向滚动容器，避免 Safari 的嵌套滚动锁死。
- 对话中的来源 chip 可直接打开成当前纸的子纸；文件操作用“放到对话纸张”表达，不暴露内部对象语义。
- 工具运行卡保留开始、完成、失败与耗时；正文使用原生流式增量，不把工具前导语混进最终回答。

## 证据边界

以下全部是零 Kernel target：生成文件、打开文件、附着纸张、阅读、显示题目、纸张重排、选中追问。正式提交建立 Attempt 后，确定性判题事件才固定进入 Knowledge / Practice。Structure 只接受学习者明确陈述并经事件契约登记的卡点；Human 只接受学习者明确确认有效的支持，不从成绩推断偏好。

## 兼容性

旧纸张没有 `parentSheetId` 或保存了坏引用时由恢复器修复；旧讲义、练习和 Session API 不变。新增来源纸张读取 API 和 Skill/Tool/Capability 都是加法变更，无数据库迁移。
